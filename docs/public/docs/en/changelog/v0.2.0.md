# v0.2.0

Account management, Docker containerized deployment, GitHub Pages docs site launch, and multiple sync/server bug fixes.

## Added

### Account Management

- Profile page for viewing and editing nickname
- Change password with a standalone modal for old and new password input
- Delete account with email confirmation; server auto-cleans related data (sync records, attachments, snapshots)
- Account entry guides users to configure server or log in when not authenticated

### Cloud Sync Improvements

- Token refresh race condition fix — concurrent requests share a single refresh Promise
- Sync status indicator shows last sync time
- Redis key namespace `qn-cloud:` prefix for multi-app shared Redis instances
- Environment variable separator unified to double underscore `__` (e.g. `DATABASE__HOST`)
- Rust HTTP request logs now include full URL

### Cloud Server Deployment

- Docker multi-stage build image (rust:1.85 + debian:bookworm-slim)
- docker-compose stack (PostgreSQL 17 + Redis 7 + quantanote-cloud)
- `.env.example` with all environment variables documented
- GitHub Actions CI pushing Docker image to Aliyun ACR
- Startup config logging now includes Email module

### Documentation Site

- Docs site config completed with missing fields (sidebar collapseControl, toc collapseControl, reading fullscreen, backend)
- GitHub Actions auto-deploy docs to GitHub Pages
- Settings page docs button links to GitHub Pages documentation site

### Other

- Settings about buttons now have icons (GitHub / BookOpen / MessageSquare)
- `pnpm bump` script now auto-updates version number in SettingsPage.tsx
- reqwest connection log level set to Warn to reduce noise
- Server email configuration module (EmailConfig / EmailService)

## Fixed

- Fixed change password API returning empty response causing frontend to treat success as failure
- Fixed delete account 422 error (`DeleteUserRequest` field default values)
- Fixed delete account foreign key constraint failure (reordered related data deletion)
- Fixed single underscore environment variable separator unable to map nested config
