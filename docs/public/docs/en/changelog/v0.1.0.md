# v0.1.0

The first public release of QuantaNote, featuring complete note editing, search, organization, version management, data management, and multi-device sync capabilities.

## Added

### Note Editing

- Markdown note editor based on Vditor IR mode with keyboard shortcut toolbar
- Full-text find and replace (`Ctrl+F` / `Ctrl+H`) with case sensitivity support
- Editor exposes `getValue`/`focus` methods via `forwardRef`

### Search & Organization

- Full-text search (FTS5 + trigram dual engine) with Chinese substring matching
- Tag management system (CRUD + many-to-many associations + filtering)
- List items display up to 3 tags with `+N` overflow indicator
- Command palette (`Ctrl+K`) for global quick search
- Search results display item summary field
- Document summary feature, auto-extracts first 10 characters
- Record title utility function, prioritizes Markdown headings as record names

### Version Management

- Version history (create/preview/restore)
- Version diff comparison, select two versions for difference analysis
- Auto-create version snapshots on editor content changes

### Attachment Management

- Attachment upload and management with image/audio/video/PDF/text preview
- Attachment paths stored as relative paths

### Data Import & Export

- JSON format data import/export (with attachments)
- ZIP format selective export/import (optional tags, attachments, version history)
- Data size estimate preview before export

### Auto Backup

- Scheduled auto-backup with configurable interval and retention count
- Backup manager for viewing and deleting historical backups
- Manual instant backup trigger

### UI & Theme

- Dark/light theme switching with system or manual mode
- Custom accent colors (built-in presets + custom color picker)
- Font localization with custom body/monospace fonts and sizes
- Text selection color synced with accent color
- Global Toast notification system
- React Error Boundary to prevent white screen from component render errors
- Loading state UI with skeleton screens and search spinners

### System Integration

- System tray with minimize/close to tray support
- System tray context menu (show window/quick capture/exit)
- Auto-start on boot setting
- Database path display with one-click open data directory
- Hidden launch mode support

### Settings Center

- General settings (theme/font/font size/accent color)
- Data management (database info/optimize/import/export)
- Backup management (auto-backup config/manual backup)
- SQL log diagnostics (configurable output to console/file)
- Keyboard shortcuts reference
- App settings stored in SQLite (replacing localStorage)

### Developer Experience

- CI/CD automated builds on tag push for Windows/Linux/macOS installers
- E2E test coverage (Playwright + Page Object pattern)
- Rust backend unit tests (commands/services/repositories)
- Configurable SQL log output (console/file/pretty format)
- Vditor resource preloading for startup performance optimization

## Fixed

- Fixed missing Vditor local resources in release builds causing Chinese language pack 404 errors
- Fixed editor paste event loss and version comparison trailing whitespace issues
- Fixed `Ctrl+C` copy in preview area being intercepted by global shortcuts
