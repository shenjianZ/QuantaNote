# 命令面板

命令面板是 QuantaNote 的键盘操作入口。按 `Ctrl + K`（macOS 为 `Command + K`）即可打开；编辑器正文获得焦点时不会抢占输入。

## 打开和搜索

| 操作 | 快捷键 | 说明 |
|---|---|---|
| 打开/关闭 | `Ctrl + K` | 在可编辑区域外切换面板 |
| 关闭 | `Esc` | 关闭面板，不改变当前页面 |

打开后输入关键词，面板会过滤笔记标题和正文搜索结果。可以点击结果，或使用 `↑` / `↓` 后按 `Enter` 打开记录；面板会跳转到记录库并打开阅读器。

## 可执行命令

面板中的命令会根据当前页面显示：

| 页面 | 可用操作 |
|---|---|
| 所有页面 | 新建笔记、打开设置 |
| 文档编辑器 | 保存当前笔记、插入图片、管理附件、打开版本历史、复制笔记 |
| 记录库（有当前记录时） | 管理附件、复制笔记 |

“插入图片”会复用编辑器的图片附件流程，并把图片插入当前光标位置；“管理附件”会打开当前笔记的附件管理器；“恢复历史版本”只打开版本面板，仍需在面板中选择具体版本确认恢复。

## 键盘流程

```text
Ctrl + K → 输入命令或笔记关键词 → 方向键 → Enter
```

命令与搜索结果使用同一套方向键选择模型。命令匹配名称和描述，搜索结果继续使用笔记全文搜索；两者可以在同一次输入中共同显示。

## 修改快捷键

前往“设置 → 快捷键”可以修改命令面板和其他应用快捷键。重复组合会显示冲突提示，清除绑定后该命令只能通过命令面板或其他入口执行。快捷键设置使用 `Mod` 记法，应用会根据 Windows/Linux/macOS 显示对应的 `Ctrl` 或 `Command`。
