# 认证

要使用 QuantaNote 的同步功能，你需要先在同步服务器上注册一个账号并通过认证。QuantaNote 使用基于 Token 的认证机制，确保你的同步操作安全可靠。

## 注册账号

首次使用同步功能时，需要先创建一个账号。

**注册步骤：**

1. 在 **设置 > 同步** 页面中，确认服务器地址已正确配置并测试通过
2. 点击"注册"按钮，打开注册弹窗
3. 填写以下信息：
   - **邮箱地址** — 用作账号标识，必须是有效的邮箱格式
   - **密码** — 设置账号密码，建议使用强密码
   - **确认密码** — 再次输入密码以确认
4. 点击"注册"按钮提交

**注册要求：**

- 邮箱地址必须是有效的格式（如 `user@example.com`）
- 密码长度至少 8 个字符
- 同一邮箱只能注册一次

**注册成功后：**

- 系统会自动使用注册的凭据进行登录
- 你的设备会获得唯一的设备 ID
- 可以立即开始使用同步功能

> **注意**：邮箱地址仅用于账号认证，QuantaNote 不会向该邮箱发送营销信息。

## 登录

如果你已经在其他设备上注册过账号，可以直接登录。

**登录步骤：**

1. 在 **设置 > 同步** 页面中，点击"登录"按钮
2. 输入邮箱地址和密码
3. 点击"登录"按钮

**Token 管理：**

登录成功后，服务器会返回两个令牌：

| 令牌 | 有效期 | 用途 |
|------|--------|------|
| Access Token | 较短（约 1 小时） | 用于所有同步 API 请求的认证 |
| Refresh Token | 较长（约 30 天） | 用于在 Access Token 过期后获取新的令牌 |

QuantaNote 会自动管理这些令牌：

- 每次同步请求都会携带 Access Token
- 当 Access Token 过期时，自动使用 Refresh Token 获取新令牌
- 如果 Refresh Token 也过期，则需要重新登录

**设备标识：**

每台设备登录后会获得一个唯一的设备 ID（Device ID）。设备 ID 用于：

- 在同步时标识变更来源
- 追踪每个设备的同步基线
- 支持多设备同时在线

## 忘记密码

如果你忘记了登录密码，可以通过以下步骤重置：

1. 在登录弹窗中，点击"忘记密码"链接
2. 输入你注册时使用的邮箱地址
3. 点击"发送重置链接"按钮
4. 系统会向你的邮箱发送一封密码重置邮件
5. 在邮件中点击重置链接，设置新密码

**注意事项：**

- 密码重置链接有时效性，请在收到邮件后尽快操作
- 如果没有收到邮件，请检查垃圾邮件文件夹
- 重置密码后，之前的 Token 会失效，需要在所有设备上重新登录

## 登出

当你不再需要同步，或者需要切换账号时，可以执行登出操作。

**登出步骤：**

1. 在 **设置 > 同步** 页面中，找到当前登录状态区域
2. 点击"登出"按钮
3. 确认登出操作

**登出后的影响：**

- 自动同步会被停止
- 本地数据不会受到任何影响
- Access Token 和 Refresh Token 会被清除
- 设备 ID 和同步基线会被保留（下次登录时可继续同步）

> **提示**：如果你要在多台设备上使用同步功能，建议每台设备都保持登录状态，以确保数据能够持续同步。
