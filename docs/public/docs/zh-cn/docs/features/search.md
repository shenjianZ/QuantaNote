# 全文搜索

QuantaNote 内置了强大的全文搜索功能，帮助你从大量记录中快速找到目标内容。搜索基于 SQLite 的 FTS5（Full-Text Search 5）扩展实现，采用双引擎策略，完美支持中文内容的搜索。

## 工作原理

QuantaNote 的全文搜索采用 **FTS5 unicode61 + trigram 双引擎** 架构，兼顾英文单词搜索和中文子串匹配的需求。

### 双引擎架构

| 引擎 | 分词器 | 适用场景 | 说明 |
|------|--------|----------|------|
| FTS5 主引擎 | `unicode61` | 英文单词匹配 | 按空格和标点分词，适合英文内容 |
| Trigram 引擎 | `trigram` | 中文字串匹配 | 按 3 字符滑动窗口建立索引，支持中文子串搜索 |

这种双引擎设计确保无论你的记录是英文、中文还是中英混合内容，都能获得良好的搜索体验。

### 索引机制

- 数据库中使用 `items_fts` 虚拟表存储全文搜索索引
- 通过数据库触发器在记录创建、更新、删除时自动维护索引
- 索引覆盖标题、内容和摘要三个字段
- 搜索操作直接在 SQLite 层面执行，性能优异

## 搜索方式

在记录库页面使用搜索栏进行搜索：

1. 点击记录库顶部的搜索输入框
2. 输入搜索关键词
3. 实时显示匹配的搜索结果

### 查询语法

FTS5 支持多种查询语法：

| 语法 | 说明 | 示例 |
|------|------|------|
| 单词搜索 | 直接输入关键词 | `笔记` |
| 多词搜索 | 空格分隔，匹配所有词 | `项目 计划` |
| 短语搜索 | 双引号包裹，精确匹配 | `"项目计划"` |
| OR 搜索 | 匹配任一词 | `项目 OR 计划` |
| 前缀搜索 | 星号通配符 | `项目*` |
| 排除搜索 | 减号排除词 | `项目 -已完成` |

## 搜索结果

搜索结果以列表形式展示，包含以下信息：

- **摘要**：显示匹配内容附近的文本片段，匹配关键词高亮显示
- **类型图标**：显示记录的类型标识
- **标题**：记录的标题文本
- **标签**：记录关联的标签
- **时间**：记录的更新时间

### 结果排序

搜索结果按相关度排序，匹配度高的记录排在前面。相关度基于 FTS5 的排名算法计算。

## 索引范围

全文搜索覆盖记录的以下字段：

| 字段 | 说明 |
|------|------|
| 标题（title） | 记录的标题文本 |
| 内容（content） | 记录的完整 Markdown 内容 |
| 摘要（summary） | 记录的摘要文本 |

这意味着你可以通过标题中的关键词、正文中的任意内容或摘要信息来搜索记录。

### 不在索引范围内的内容

- 标签名称（标签过滤请使用记录库的标签筛选功能）
- 附件文件名和内容
- 版本历史内容

## 性能说明

- FTS5 索引使搜索操作的时间复杂度远低于全表扫描
- 即使记录数量达到数千条，搜索响应时间仍在毫秒级别
- 索引的维护（创建和更新）在后台自动完成，不影响正常使用
- WAL 日志模式确保搜索和写入操作可以并发执行
