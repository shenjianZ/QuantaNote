# 数据管理

QuantaNote 提供完善的数据管理功能，帮助你安全地导入、导出和备份所有笔记数据。数据以 SQLite 数据库的形式存储在本地，确保你对数据拥有完全的控制权。

## 功能概览

数据管理模块包含以下核心能力：

- **导入与导出** — 支持 JSON 和 ZIP 两种格式，灵活选择需要导出的内容范围
- **自动备份** — 可配置的定时备份策略，保护你的数据安全
- **手动备份** — 一键触发即时备份，随时创建数据快照
- **备份管理** — 查看备份历史、管理磁盘空间

## 为什么需要数据管理？

作为本地优先的应用，QuantaNote 将你的所有数据保存在本地设备上。这意味着：

1. **数据主权** — 你的数据始终在你的设备上，不会强制上传到云端
2. **离线可用** — 不依赖网络连接即可访问所有功能
3. **隐私保护** — 数据不经第三方服务器处理

但同时，数据管理也变得尤为重要。定期备份和灵活的导入导出机制可以：

- 防止因设备故障导致数据丢失
- 方便在不同设备之间迁移数据
- 归档和长期保存重要笔记

## 数据存储位置

QuantaNote 的所有本地数据存储在以下目录中：

```
~/.quantanote/
├── quanta_note.sqlite    # 主数据库文件
├── backups/              # 备份文件目录
└── attachments/          # 附件文件目录
```

在 Windows 系统上，默认路径为 `%USERPROFILE%\.quantanote\`。

> **提示**：如果你同时使用了同步功能，本地数据会与远程服务器保持同步，但备份始终是本地操作。
