# 导入与导出

QuantaNote 支持两种格式的数据导入导出：**JSON** 和 **ZIP**。JSON 格式适合程序化处理和数据交换，ZIP 格式则打包了所有内容（包括附件文件），适合完整备份和迁移。

你可以通过 **设置 > 数据管理** 页面访问导入导出功能。

## 导出为 ZIP

ZIP 格式是推荐的导出方式，它会将所有数据打包成一个压缩文件，包括笔记内容、附件、标签和版本历史。

**操作步骤：**

1. 打开设置页面，进入"数据管理"区域
2. 点击"导出"按钮，系统会弹出导出选项弹窗
3. 在弹窗中选择导出范围和选项：
   - **包含附件** — 是否导出附件文件（图片、文档等）
   - **包含版本历史** — 是否导出笔记的历史版本记录
   - **包含标签** — 是否导出标签及其关联关系
4. 系统会自动计算预估导出大小
5. 确认后点击"导出"按钮，选择保存位置

**ZIP 文件结构：**

```
quantanote_export_20260503.zip
├── data.json              # 所有笔记和元数据
├── attachments/           # 附件文件
│   ├── abc123.pdf
│   └── def456.png
└── meta.json              # 导出元信息（版本、时间戳等）
```

> **注意**：如果数据量较大，导出过程可能需要几秒到几十秒不等。在此期间请勿关闭应用。

## 导出为 JSON

JSON 格式导出仅包含结构化数据，不包含附件文件本身。适合以下场景：

- 数据分析和统计
- 迁移到其他笔记工具
- 与第三方程序集成

**导出内容：**

- 所有笔记（Items）的标题、内容、创建和修改时间
- 所有标签（Tags）及其名称
- 笔记与标签的关联关系（ItemTags）
- 附件的元数据（文件名、大小、类型等）
- 版本历史记录

JSON 导出的数据结构与数据库表结构一致，使用 UTF-8 编码。

## 从 ZIP 导入

从 ZIP 文件导入可以恢复之前导出的完整数据。

**操作步骤：**

1. 在设置 > 数据管理中点击"导入"按钮
2. 选择 ZIP 文件（仅接受 `.zip` 格式）
3. 系统解析文件后，显示导入预览信息：
   - 包含的笔记数量
   - 包含的附件数量
   - 包含的标签数量
4. 选择导入选项：
   - **覆盖现有数据** — 勾选后会替换本地同 ID 的记录；不勾选则跳过已存在的记录
5. 确认后开始导入

**导入冲突处理：**

| 覆盖开关 | 已存在记录 | 不存在记录 |
|----------|-----------|-----------|
| 开启 | 覆盖本地数据 | 新建记录 |
| 关闭 | 跳过，保留本地 | 新建记录 |

> **建议**：在导入前先创建一个手动备份，以防导入结果不符合预期时可以回退。

## 从 JSON 导入

JSON 导入流程与 ZIP 导入类似，但不会导入附件文件（因为 JSON 导出不包含附件）。

1. 选择 `.json` 文件
2. 查看导入预览
3. 选择是否覆盖现有数据
4. 确认导入

JSON 导入适用于从其他工具迁移数据的场景。你需要确保 JSON 文件的格式与 QuantaNote 的数据结构兼容。

## 数据大小估算

在执行导出之前，QuantaNote 会自动计算并显示预估的导出大小，帮助你：

- 评估导出文件是否会过大
- 决定是否排除附件或版本历史以减小文件体积
- 提前规划存储空间

**大小明细包括：**

| 类别 | 说明 |
|------|------|
| 笔记内容 | 所有 Item 的文本内容大小 |
| 附件文件 | 所有附件文件的原始大小 |
| 版本历史 | 所有版本记录的大小 |
| 元数据 | 标签、关联关系等元信息大小 |
| **总计** | 压缩前的预估总大小（ZIP 格式会有压缩） |

> **提示**：ZIP 格式会自动压缩数据，实际文件大小通常小于预估大小。图片类附件的压缩率较低，文本内容的压缩率较高。
