# Markdown 编辑器

QuantaNote 内置基于 [Vditor](https://b3log.org/vditor/) 的 Markdown 编辑器，采用 **IR（Instant Rendering，即时渲染）模式**，为你提供流畅的编辑体验。

IR 模式结合了 Markdown 纯文本编辑的灵活性和所见即所得编辑器的直观性——输入 Markdown 语法后即时渲染为格式化文本，同时保留语法的可编辑性，让你在编辑时就能看到最终效果。

## 编辑模式

QuantaNote 默认使用 Vditor 的 IR（即时渲染）模式：

- **即时渲染**：输入 Markdown 语法标记后，内容区域立即渲染为格式化文本
- **语法可编辑**：将光标移动到已渲染的内容上，会显示原始 Markdown 语法，方便修改
- **混合体验**：编辑过程中同时看到 Markdown 语法和渲染效果，无需切换预览

IR 模式是 Vditor 的核心特色，让你无需在编辑和预览之间来回切换，大幅提升编辑效率。

## 工具栏参考

编辑器提供了完整的格式化工具栏，点击按钮即可插入对应语法：

| 按钮 | 功能 | Markdown 语法 |
|------|------|---------------|
| H1-H6 | 标题 | `# 标题` ~ `###### 标题` |
| **B** | 加粗 | `**加粗文本**` |
| *I* | 斜体 | `*斜体文本*` |
| ~~S~~ | 删除线 | `~~删除线文本~~` |
| 1. | 有序列表 | `1. 列表项` |
| - | 无序列表 | `- 列表项` |
| ☐ | 待办事项 | `- [ ] 待办项` |
| > | 引用 | `> 引用文本` |
| Code | 代码块 | ```` ```代码块``` ```` |
| `Code` | 行内代码 | `` `行内代码` `` |
| 🔗 | 链接 | `[链接文本](URL)` |
| 📊 | 表格 | `| 列1 | 列2 |` |
| ↩ | 撤销 | 撤销上一步操作 |
| ↪ | 重做 | 重做已撤销的操作 |

## 搜索与替换

编辑器内置了搜索与替换功能，方便在长文档中定位和修改内容：

- **打开搜索**：按 `Ctrl + F` 打开搜索栏
- **打开替换**：按 `Ctrl + H` 打开搜索替换栏
- **区分大小写**：支持切换大小写敏感模式
- **导航结果**：搜索结果高亮显示，可通过上下箭头按钮逐个跳转
- **批量替换**：输入替换文本后，可逐个替换或全部替换

## 支持的语法

QuantaNote 的 Markdown 编辑器支持以下扩展语法（基于 GFM 规范）：

### GFM 扩展

| 语法 | 说明 | 示例 |
|------|------|------|
| 表格 | 使用竖线和横线创建表格 | `| 列1 \| 列2 \|` |
| 任务列表 | 带复选框的列表 | `- [x] 已完成` |
| 删除线 | 添加删除线效果 | `~~已删除~~` |

### 代码块

使用三个反引号包裹代码块，支持语法高亮：

````
```javascript
function hello() {
  console.log("Hello, QuantaNote!");
}
```
````

### 链接和图片

| 语法 | 说明 |
|------|------|
| `[文本](URL)` | 超链接 |
| `![描述](URL)` | 图片（支持本地附件路径） |

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + B` | 加粗 |
| `Ctrl + I` | 斜体 |

| `Ctrl + F` | 打开搜索 |
| `Ctrl + H` | 打开搜索替换 |

| `Ctrl + Shift + Z` | 重做 |
| `Ctrl + Shift + K` | 插入代码块 |
| `Ctrl + Shift + 7` | 有序列表 |
| `Ctrl + Shift + 8` | 无序列表 |
| `Ctrl + Shift + 9` | 引用块 |
| `Ctrl + Enter` | 保存（工作台）/ 换行 |
| `Tab` | 缩进 |
| `Shift + Tab` | 取消缩进 |

掌握这些快捷键可以让你的编辑效率大幅提升。
