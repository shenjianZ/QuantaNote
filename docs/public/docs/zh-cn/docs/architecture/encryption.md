# 本地加密设计

本文记录 QuantaNote 本地加密笔记库的设计约束。当前版本尚未实现静态加密，`items.encrypted` 只是预留字段，不能据此认为笔记内容已经加密。

## 目标和边界

本地加密的目标是保护数据库文件、附件和备份文件在设备离线或被其他本机用户读取时的内容。它不能防御已经控制当前用户会话的恶意程序，也不能替用户找回遗失的主密码。

实现前必须明确以下原则：

- 密钥只在用户解锁后的进程内存中短暂存在，主密码和派生密钥不写入 SQLite、设置文件、日志或同步请求。
- 用户忘记主密码时不提供绕过机制；恢复依赖用户主动保存的加密备份或导出的恢复材料。
- 加密迁移前必须先完成可验证的逻辑备份，并支持失败回滚；不能在没有备份的情况下原地覆盖明文。
- 附件属于笔记内容的一部分，不能只加密 Markdown 正文而继续以明文保存附件。

## 密钥管理和解锁/锁定流程

### 密钥层次

建议使用成熟库实现以下层次，不自行设计密码学算法：

1. 首次启用时生成随机 Vault Data Encryption Key（DEK），不由用户密码直接充当数据密钥。
2. 使用 Argon2id 从用户主密码和随机 salt 派生 Key Encryption Key（KEK）。Argon2id 的参数写入加密元数据，便于未来升级参数。
3. 使用 XChaCha20-Poly1305 以随机 nonce 加密 DEK，保存“算法版本、salt、参数、nonce、wrapped DEK”元数据。
4. 每条笔记、版本和附件使用独立随机 nonce，并将记录类型、记录 ID 和字段名作为 AAD，防止密文被挪到其他记录后仍能通过校验。
5. Rust 实现优先采用 `argon2`、`chacha20poly1305`、`zeroize` 等成熟库；随机数必须来自系统安全随机源。库升级和算法参数变化通过明确的 envelope 版本处理。

### 状态机

| 状态 | 允许的操作 | 内存中的密钥 |
|------|------------|--------------|
| `locked` | 打开应用、显示非敏感状态、输入主密码 | 无 |
| `unlocking` | 校验密码和解包 DEK | 临时存在，失败后清零 |
| `unlocked` | 读写、搜索、同步、备份 | 仅进程内，空闲超时或手动锁定时清零 |
| `locking` | 停止任务、清理临时索引、清零密钥 | 正在清零 |

锁定必须先取消或等待正在进行的保存、导入、同步和备份任务，清除内存中的明文缓存与搜索索引，然后再清零 DEK/KEK。关闭窗口不应被默认为锁定成功，应用退出前仍需完成数据库 checkpoint 和临时文件清理。

## 搜索、同步和备份

### 搜索

现有 `items_fts` 是持久化 FTS5 表，包含明文内容，因此加密笔记启用后不能继续把明文写入该表。后续实现应采用以下策略：

- `locked` 状态下不搜索加密笔记正文、摘要、版本和附件内容；非加密元数据是否可搜索必须由产品设置明确决定。
- `unlocked` 状态下在内存中解密并建立临时索引，锁定时删除临时索引；不能通过普通 SQLite 备份保留它。
- 搜索结果的上下文和高亮也必须在锁定时清空，避免 UI 状态或日志残留明文。

### 同步

同步服务端只接收版本化密文、公开元数据和完整性哈希，不接收主密码、KEK 或 DEK。冲突比较使用密文版本和字段哈希；需要字段级合并时，必须在本地解密后完成，再以新的密文版本上传。服务端无法替用户解锁或合并明文。

附件同步同样传输密文附件。若用户未解锁，允许下载密文到受控的暂存位置，但不能将其作为可预览明文交给前端。

### 备份和恢复

- 逻辑 ZIP 备份应保存加密后的记录和附件，不应把加密笔记临时解密后写入 ZIP。
- SQLite 文件备份只能作为已完成加密迁移后的数据库副本；未加密库不能通过文件扩展名或 `encrypted` 字段冒充加密备份。
- 恢复前校验 envelope 版本、认证标签和附件完整性；恢复失败不得替换当前库。
- 备份密码不能写入自动备份设置。自动备份要么使用已经解锁的 Vault 会话密钥完成受控加密，要么明确提示用户它不包含加密笔记。

## 迁移和兼容

`encrypted` 字段在真正实现前只作为兼容字段，不作为安全能力开关。正式实现时需要新增明确的 Vault 元数据和加密状态字段，并提供一次性的迁移向导：先验证备份，再逐条加密、校验、提交，最后删除旧明文。旧版本打开加密库时必须安全拒绝，而不是把密文当作 Markdown 展示或覆盖写回。

在运行时实现和安全测试完成前，文档、设置界面和 IPC 类型都必须使用“预留/未实现”的措辞。
