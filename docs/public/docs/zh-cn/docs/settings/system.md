# 系统集成

系统集成设置控制 QuantaNote 与操作系统的交互方式，包括窗口行为、开机自启和系统托盘功能。这些设置帮助你将 QuantaNote 无缝融入日常工作流程。

## 窗口行为

窗口行为设置决定 QuantaNote 在你关闭或最小化窗口时的响应方式。通过合理配置，可以让应用在后台持续运行，随时可以快速调出。

### 最小化到托盘

启用后，点击窗口的最小化按钮不会将窗口最小化到任务栏，而是隐藏到系统托盘区域。

| 选项 | 说明 |
|------|------|
| **开启** | 点击最小化按钮时，窗口隐藏到系统托盘，不占用任务栏空间 |
| **关闭**（默认） | 点击最小化按钮时，窗口正常最小化到任务栏 |

**适用场景：**

- 长时间使用 QuantaNote 记录笔记，希望随时通过托盘快速调出
- 屏幕空间有限，不希望任务栏被过多图标占据
- 配合「关闭时继续运行」使用，实现完全的托盘化运行

### 关闭时继续运行

启用后，点击窗口的关闭按钮不会退出应用，而是将窗口隐藏到系统托盘继续运行。

| 选项 | 说明 |
|------|------|
| **开启** | 点击关闭按钮时，窗口隐藏到系统托盘，应用继续在后台运行 |
| **关闭**（默认） | 点击关闭按钮时，正常退出应用 |

**适用场景：**

- 经常需要临时关闭窗口但不希望丢失应用状态
- 希望 QuantaNote 始终在后台待命，随时通过托盘图标重新打开
- 配合自动备份功能，确保应用始终在后台执行定时备份

> **注意**：启用此选项后，要完全退出应用需要通过系统托盘右键菜单中的「退出」选项。

## 开机自启

启用开机自启后，QuantaNote 会在操作系统启动时自动运行。

| 选项 | 说明 |
|------|------|
| **开启** | 系统启动时自动启动 QuantaNote |
| **关闭**（默认） | 需要手动启动 QuantaNote |

### 技术实现

开机自启通过 Tauri 的 `setAutostart` 命令实现，底层调用操作系统的自启动注册机制：

- **Windows**：通过注册表项或启动文件夹注册
- **macOS**：通过 LaunchAgent 配置
- **Linux**：通过 `.desktop` 文件的 `autostart` 配置

### 配合建议

推荐配合以下设置一起使用，获得最佳体验：

1. 开启 **开机自启**
2. 开启 **关闭时继续运行**
3. 开启 **最小化到托盘**

这样 QuantaNote 会在系统启动时自动在后台运行，需要时通过托盘图标快速打开，不需要时隐藏到托盘不占用屏幕空间。

## 系统托盘

QuantaNote 支持系统托盘功能，当应用被最小化或隐藏到托盘时，托盘图标提供以下功能：

### 托盘图标

- 托盘区域显示 QuantaNote 图标
- 单击托盘图标可以重新显示应用主窗口
- 图标状态会根据应用当前状态变化

### 右键菜单

在托盘图标上点击右键会弹出上下文菜单，提供以下操作：

| 菜单项 | 功能 |
|--------|------|
| **显示窗口** | 将隐藏的应用窗口重新显示到前台 |
| **新建记录** | 快速打开工作台新建一条记录 |
| **退出** | 完全退出 QuantaNote 应用 |

> **提示**：如果你经常需要快速记录，可以将 QuantaNote 设置为开机自启并最小化到托盘，通过托盘右键菜单的「新建记录」快速捕捉灵感。

## 悬浮球

悬浮球是一个独立的桌面快捷窗口，可显示在其他窗口上方。它适合在主窗口隐藏或最小化时继续保留一个轻量入口。

| 设置 | 说明 |
|------|------|
| **悬浮球** | 开启或关闭悬浮球窗口 |
| **悬浮球位置** | 设置屏幕物理 X/Y 坐标；留空时自动放置在主屏幕右下角 |
| **重置** | 清除手动位置，让应用重新计算默认位置 |

悬浮球菜单包含快速笔记、搜索、最近记录、新建完整笔记和关闭悬浮球。更完整的使用说明见 [悬浮球](../features/floating-ball)。
