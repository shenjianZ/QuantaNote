# 开发

欢迎使用 QuantaNote 开发文档。本章节面向希望参与 QuantaNote 开发的贡献者，涵盖了从源码构建、技术架构到测试和贡献流程的完整指南。

无论你是想要修复一个 Bug、添加新功能，还是仅仅想了解 QuantaNote 的内部实现，都可以在以下章节中找到所需信息。建议先阅读「从源码构建」和「项目结构」，以便快速搭建开发环境并理解代码组织方式。

## 章节目录

1. **[从源码构建](/docs/development/building)**

   了解如何搭建本地开发环境，克隆代码仓库并从源码构建 QuantaNote。包含开发模式和生产构建的完整说明。

2. **[技术栈](/docs/development/tech-stack)**

   了解 QuantaNote 所使用的前后端技术选型，包括 React、TypeScript、Rust、Tauri 等核心依赖及其版本。

3. **[项目结构](/docs/development/project-structure)**

   了解 QuantaNote 的目录结构设计和代码组织方式，包含前端和后端的详细目录树说明。

4. **[开发命令](/docs/development/commands)**

   常用开发命令速查表，包括前端开发、Tauri 开发、测试、格式化和类型检查等命令。

5. **[测试指南](/docs/development/testing)**

   了解 QuantaNote 的三层测试策略：前端单元测试、Rust 单元测试和 E2E 端到端测试。

6. **[贡献指南](/docs/development/contributing)**

   了解如何向 QuantaNote 贡献代码，包括 Fork 流程、分支命名规范、代码风格要求和 PR 提交流程。

## 快速开始

如果你是第一次参与开发，建议按以下顺序阅读：

1. 从源码构建 — 搭建开发环境
2. 项目结构 — 了解代码组织
3. 开发命令 — 熟悉常用命令
4. 贡献指南 — 了解贡献流程
