# Tags

Tags are a flexible organizational system in QuantaNote that allows you to label and categorize your items with colored labels. Tags provide a many-to-many relationship with items — each item can have multiple tags, and each tag can be applied to multiple items.

## Creating Tags

To create a new tag:

1. Open the **Tag Manager** modal from the Library toolbar or the Settings page.
2. Click the **"New Tag"** button.
3. Enter a name for the tag.
4. Select a color from the predefined color palette.
5. Click **"Create"** to save the tag.

Tags are stored globally in your database and are available for assignment to any item. Tag names must be unique — you cannot create two tags with the same name.

## Tag Colors

Each tag is assigned one of the following predefined colors to provide visual differentiation:

| Color | Hex Code | Use Case Example |
|-------|----------|------------------|
| Red | `#ef4444` | Urgent, important |
| Orange | `#f97316` | Work, tasks |
| Yellow | `#eab308` | Ideas, brainstorm |
| Green | `#22c55e` | Done, completed |
| Blue | `#3b82f6` | Reference, research |
| Purple | `#a855f7` | Personal, creative |
| Pink | `#ec4899` | Review, follow-up |
| Gray | `#6b7280` | Archive, misc |

Tag colors are displayed as background tints on tag badges throughout the app, including Library cards, the Reader Drawer, and the Document Editor.

## Assigning Tags

To assign tags to an item:

1. Open the **Tag Picker Modal** — accessible from an item's context menu in the Library, the Reader Drawer, or the Document Editor toolbar.
2. The modal displays all available tags with their colors.
3. **Multi-select** — Click tags to toggle them on or off for the current item. Selected tags are highlighted.
4. Click **"Apply"** to save the tag assignments.

Tags can also be assigned during quick capture by using the Tag Picker after saving a note.

## Filtering by Tag

In the Library view, you can filter the item list by a specific tag:

- Click on any **tag badge** on an item card to filter the Library to show only items with that tag.
- Use the **tag filter dropdown** in the Library toolbar to select a tag from the full list.
- When a tag filter is active, a clear button appears next to the filter so you can remove it.
- Tag filtering works in combination with the **All / Pinned / Favorites** tabs.

This allows you to quickly narrow down your collection to exactly the items you need.

## Managing Tags

The **Tag Manager** modal provides full tag management capabilities:

- **Rename** — Change the name of an existing tag. All items assigned to that tag are updated automatically.
- **Recolor** — Change the color of a tag. The new color is reflected immediately across all items.
- **Delete** — Remove a tag permanently. This also removes the tag from all items it was assigned to. A confirmation prompt prevents accidental deletion.
- **Reorder** — Tags can be reordered by dragging them in the Tag Manager (if supported).

Access the Tag Manager from the Library toolbar or the Settings page.

## Tag Statistics

The Tag Manager and Library provide tag statistics:

- **Item Count** — Each tag displays the number of items it is assigned to.
- **Empty Tags** — Tags with zero items are still visible in the Tag Manager, allowing you to reuse or delete them.
- **Usage Overview** — The Tag Manager may show tags sorted by usage count, helping you identify your most-used categories.

Tag statistics help you maintain a clean and relevant tag taxonomy by identifying unused or underused tags.
