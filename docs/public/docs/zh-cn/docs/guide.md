# 使用指南

欢迎使用 QuantaNote 使用指南。本指南将带你从零开始，逐步了解和掌握 QuantaNote 的各项功能。

无论你是第一次使用 QuantaNote，还是希望深入了解某个特定功能，都可以在以下章节中找到所需的信息。建议按顺序阅读，以便系统地了解 QuantaNote 的使用方法。

如果你已经熟悉 QuantaNote 的基本操作，也可以直接跳到你感兴趣的章节。

## 章节目录

1. **[介绍 QuantaNote](/docs/guide/introduction)**

   了解 QuantaNote 的定位、设计理念和核心功能。在这一章中，你将了解到：

   - QuantaNote 是什么，它能为你做什么
   - 为什么选择「本地优先」的数据管理方式
   - QuantaNote 提供的核心功能概览
   - 适合使用 QuantaNote 的典型场景

   如果你还在评估 QuantaNote 是否适合自己，从这里开始。

2. **[安装](/docs/guide/installation)**

   下载并安装 QuantaNote。包含 Windows、macOS 和 Linux 三大平台的详细安装步骤，以及首次启动时的注意事项：

   - 系统要求与兼容性
   - 各平台安装方法（安装包、便携版、AppImage）
   - 首次启动的自动初始化流程
   - 如何卸载及数据目录清理

3. **[快速上手](/docs/guide/quick-start)**

   5 分钟学会 QuantaNote 的基本操作：

   - 在工作区创建第一条笔记
   - 在记录库中浏览、筛选和排序
   - 使用文档编辑器撰写和格式化内容
   - 创建标签并组织笔记
   - 使用全局搜索快速查找内容

   适合希望立刻开始使用的用户。

## 阅读建议

- **新用户**：建议从「介绍」开始，按顺序阅读到「快速上手」，然后直接开始使用 QuantaNote。
- **有经验的用户**：可以直接查阅「快速上手」回顾操作方式，或浏览 [功能详解](/docs/features/data) 了解高级功能。
- **开发者**：如果你希望参与开发或进行二次开发，请参阅 [开发者文档](/docs/developer/architecture)。

如果你在使用过程中遇到问题，可以通过以下方式获取帮助：

- 在 [GitHub Issues](https://github.com/shenjianZ/QuantaNote/issues) 提交问题
- 查阅 [更新日志](/changelog) 了解版本变更
