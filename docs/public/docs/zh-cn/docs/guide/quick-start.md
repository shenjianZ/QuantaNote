# 快速上手

本指南将帮助你在 5 分钟内掌握 QuantaNote 的基本操作。完成后，你将能够自如地创建、编辑、组织和查找笔记。

## 创建第一条笔记

启动 QuantaNote 后，你会看到**工作区**页面，这是快速记录的入口。

1. 在页面中央的输入框中，直接输入你的内容。
2. 输入完成后，按下 `Ctrl + Enter` 保存笔记。
3. 保存后，笔记会出现在下方的预览区域，同时自动添加到记录库中。

> **提示**：工作区适合快速捕捉灵感和简短记录。如果需要撰写更长的文档，可以在记录库中打开笔记进入全屏编辑器。

工作区页面支持 Markdown 实时预览，你可以在输入框中使用 Markdown 语法，下方会即时显示渲染效果。

## 浏览记录库

点击顶部导航栏的**记录库**进入笔记管理页面。这里汇集了你的所有笔记，提供多种浏览和筛选方式。

### 筛选标签页

记录库顶部提供以下筛选标签页：

- **全部** — 显示所有笔记
- **置顶** — 只显示被置顶的笔记
- **收藏** — 只显示被标记为收藏的笔记

### 排序方式

支持多种排序方式，包括：

- **按更新时间** — 最近更新的笔记排在前面（默认）
- **按创建时间** — 最新创建的笔记排在前面
- **按标题** — 按标题字母顺序排列

### 笔记操作

在记录库中，你可以对笔记执行以下操作：

- **置顶/取消置顶** — 将重要笔记固定在顶部
- **收藏/取消收藏** — 标记喜爱的笔记
- **删除** — 移除不需要的笔记（删除后可通过版本历史恢复）

## 编辑文档

在记录库中点击任意笔记，或双击工作区中的笔记预览卡片，即可进入**文档编辑器**页面。

### 标题和摘要

- **标题**：页面顶部可以编辑笔记标题。清晰的标题有助于后续搜索和识别。
- **摘要**：可以为笔记添加简短摘要，方便在记录库列表中快速了解内容。

### 编辑器功能

QuantaNote 使用 Vditor 编辑器，提供所见即所得的 Markdown 编辑体验：

- **工具栏**：编辑器顶部提供常用格式化按钮（加粗、斜体、标题、列表、代码块、链接等）
- **实时预览**：编辑时即时渲染 Markdown 格式
- **快捷键**：支持常用 Markdown 快捷键（如 `Ctrl+B` 加粗、`Ctrl+I` 斜体）
- **自动保存**：编辑内容会自动保存，无需手动操作

### 代码块与数学公式

支持在笔记中插入代码块和数学公式：

- 使用三个反引号 `` ``` `` 包裹代码块，支持语法高亮
- 使用 `$$` 包裹数学公式（基于 KaTeX 渲染）

## 使用标签

标签是 QuantaNote 中组织笔记的核心方式。通过为笔记分配标签，你可以灵活地分类和筛选内容。

### 创建标签

1. 打开**标签管理器**（通过侧边栏或设置页面访问）。
2. 点击「新建标签」按钮。
3. 输入标签名称，并选择一个标识颜色。
4. 点击确认创建标签。

### 为笔记分配标签

- 在编辑笔记时，通过标签选择器为当前笔记添加一个或多个标签。
- 在记录库中，可以批量选择笔记并统一添加标签。

### 按标签筛选

- 在记录库页面的侧边栏中，点击标签名称即可筛选显示该标签下的所有笔记。
- 支持多标签组合筛选。

## 搜索

QuantaNote 提供强大的全文搜索功能，帮助你在大量笔记中快速找到需要的内容。

### 命令面板

按下 `Ctrl + K` 打开全局命令面板。在搜索框中输入关键词，即可实时搜索所有笔记的标题和内容。

### 全文搜索特性

- **中英文支持**：基于 FTS5 引擎，同时支持中文和英文分词
- **毫秒级响应**：即使有数千条笔记，搜索结果也能即时呈现
- **高亮匹配**：搜索结果中会高亮显示匹配的关键词

### 搜索技巧

- 输入多个关键词可以匹配同时包含这些关键词的笔记
- 搜索会匹配笔记的标题和正文内容
- 搜索结果按相关度排序
