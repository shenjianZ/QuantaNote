# 工作台

工作台是 QuantaNote 的核心入口之一，专为快速捕捉灵感而设计。当你有一个想法、一段文字或一条笔记需要记录时，工作台让你能够以最少的操作完成记录。

工作台的设计理念是 **"输入即记录"**——打开应用即可开始输入，无需创建文件、选择目录或填写表单。

## 快速记录

工作台提供了一个简洁的输入区域，支持 Markdown 格式的文本输入。

**使用方式：**

1. 在输入框中输入你要记录的内容
2. 使用 `Ctrl + Enter` 快捷键保存
3. 保存完成后，编辑器自动清空，可以立即开始下一条记录

这种设计让你可以连续快速地记录多条笔记，而无需手动新建或重置编辑器。

## 编辑器工具栏

工作台内置了精简的 Markdown 格式化工具栏，无需记忆语法即可快速格式化内容。工具栏包含以下功能：

| 按钮 | 功能 | Markdown 语法 |
|------|------|---------------|
| 标题 | 插入标题（H1-H6） | `# 标题` |
| **B** | 加粗文本 | `**加粗**` |
| *I* | 斜体文本 | `*斜体*` |
| 列表 | 插入无序列表 | `- 列表项` |
| 代码 | 插入行内代码 | `` `代码` `` |
| 链接 | 插入超链接 | `[文本](URL)` |
| 表格 | 插入表格模板 | `| 列1 | 列2 |` |

点击工具栏按钮后，会在光标位置插入对应的 Markdown 语法标记。

## 保存状态

保存操作完成后，QuantaNote 会提供清晰的状态反馈：

- 保存成功后编辑器自动清空，表示内容已成功保存为一条新记录
- 新记录会自动出现在记录库中
- 如果保存过程中出现异常，编辑器不会清空，确保内容不丢失

## 标题自动提取

工作台会从你输入的内容中自动提取标题，无需手动填写：

- **提取规则**：自动将内容的第一行文本作为记录标题
- **智能处理**：如果第一行是 Markdown 标题语法（如 `# 标题`），会自动去除 `#` 符号，提取纯文本作为标题
- **默认标题**：如果内容为空或无法提取有效标题，系统会生成一个默认标题

自动提取的标题在记录库的卡片视图中显示，方便你快速识别每条记录的内容。

## 快捷操作

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 保存记录 | `Ctrl + Enter` | 保存当前内容并清空编辑器 |
| 切换页面 | 导航栏 | 点击顶栏图标切换到记录库或其他页面 |

工作台的设计目标是让记录的过程尽可能简单和快速，减少一切不必要的操作步骤。
