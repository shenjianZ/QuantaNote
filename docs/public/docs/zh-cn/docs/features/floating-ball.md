# 悬浮球

悬浮球是 QuantaNote 的桌面快捷入口。启用后，它会以一个小型透明窗口显示在其他窗口上方，让你在不切回主窗口的情况下创建笔记、打开搜索或回到最近记录。

## 启用方式

在 **设置 → 外观 → 窗口行为** 中开启「悬浮球」。开启后，QuantaNote 会创建一个独立的悬浮窗口。

| 设置 | 说明 |
|------|------|
| 悬浮球 | 控制悬浮球窗口的显示与关闭 |
| 悬浮球位置 | 可填写屏幕物理 X/Y 坐标；留空时自动显示在主屏幕右下角 |
| 重置 | 清除手动坐标，让应用重新根据当前屏幕计算默认位置 |

悬浮球位置会持久保存。拖动悬浮球后，QuantaNote 会记录新的屏幕坐标，下次启动或重新开启悬浮球时继续使用。

## 快速操作菜单

单击悬浮球会展开径向菜单。菜单当前提供以下入口：

| 操作 | 说明 |
|------|------|
| 快速笔记 | 打开独立快速笔记窗口，适合临时记录 |
| 搜索 | 打开命令面板，快速搜索记录 |
| 最近记录 | 切换到记录库，查看最近内容 |
| 新建完整笔记 | 在主窗口中创建一条新记录并进入编辑流程 |
| 关闭悬浮球 | 关闭悬浮球并同步关闭设置项 |

展开菜单时，悬浮窗口会临时扩大以容纳菜单；收起后恢复为小尺寸球体。

## 快速笔记窗口

快速笔记窗口是一个独立的轻量编辑器，适合在当前工作流中临时捕捉内容。

- 使用 Markdown 编辑器输入内容。
- 点击保存按钮或按 `Ctrl + Enter` 保存。
- macOS 上可使用 `⌘ + Enter` 保存。
- 按 `Esc` 可关闭快速笔记窗口。
- 保存成功后，内容会作为普通记录写入记录库，并自动提取标题。

快速笔记保存失败时会显示错误提示，编辑内容不会主动清空。

## 拖拽与多屏

悬浮球收起状态下可拖拽移动。应用会根据显示器工作区计算默认位置，并在多屏环境中优先将位置限制在可见工作区内。

当你在设置中手动填写坐标时，应使用操作系统提供的物理屏幕坐标。若位置不可见或移动到屏幕外，使用「重置」即可恢复自动布局。

## 使用建议

- 经常需要临时记录时，开启悬浮球并配合快速笔记使用。
- 如果只需要后台待命，可以同时开启「关闭时继续运行」和「最小化到托盘」。
- 多屏切换后如果悬浮球位置不理想，先使用「重置」让应用重新计算默认位置。
