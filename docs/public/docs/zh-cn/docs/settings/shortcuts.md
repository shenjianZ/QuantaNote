# 快捷键

QuantaNote 提供了丰富的快捷键支持，帮助你以键盘为中心高效操作。熟练使用快捷键可以大幅提升工作效率，减少鼠标操作。

## 全局快捷键

全局快捷键在应用的任何页面都可以使用。

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl + K` | 命令面板 | 打开全局搜索面板，输入关键词搜索并快速跳转到任意记录 |
| `Ctrl + ,` | 打开设置 | 直接跳转到设置页面 |

### 命令面板

`Ctrl + K` 是 QuantaNote 中最重要的快捷键之一，打开的命令面板支持：

- 输入关键词实时搜索所有记录
- 搜索结果即时显示，点击即可跳转
- 支持标题和内容的全文搜索
- 按 `Esc` 关闭命令面板

## 工作台快捷键

工作台页面用于快速记录灵感，以下快捷键可以加速记录流程。

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl + Enter` | 快速保存 | 保存当前输入内容为新记录，保存后自动清空编辑器 |
| `Tab` | 缩进 | 在编辑器中插入缩进 |
| `Shift + Tab` | 反向缩进 | 减少缩进级别 |

### 快速记录工作流

使用快捷键的最快记录流程：

1. 打开 QuantaNote（或通过托盘图标切换到应用）
2. 直接开始输入内容
3. 按 `Ctrl + Enter` 保存
4. 继续输入下一条记录

## 编辑器快捷键

文档编辑器（Vditor）支持丰富的编辑快捷键，包括通用快捷键和 Markdown 特定快捷键。

### 通用编辑快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl + S` | 保存 | 手动保存当前编辑内容（编辑器也会自动保存） |
| `Ctrl + F` | 查找 | 打开搜索栏，在文档中搜索指定文本 |
| `Ctrl + H` | 替换 | 打开查找替换栏，搜索并替换文本 |
| `Ctrl + Z` | 撤销 | 撤销上一步操作 |
| `Ctrl + Shift + Z` | 重做 | 恢复已撤销的操作 |
| `Ctrl + A` | 全选 | 选中编辑器中的所有内容 |
| `Ctrl + C` | 复制 | 复制选中的文本，并显示复制结果提示 |
| `Ctrl + X` | 剪切 | 剪切选中的文本 |
| `Ctrl + V` | 粘贴 | 粘贴剪贴板中的内容，并显示粘贴结果提示 |

### 查找替换

编辑器内置查找替换功能，支持以下操作：

| 操作 | 快捷键/按钮 | 说明 |
|------|-------------|------|
| 打开查找 | `Ctrl + F` | 在底部打开搜索栏 |
| 打开替换 | `Ctrl + H` | 在搜索栏中显示替换输入框 |
| 下一个匹配 | `Enter` | 跳转到下一个匹配项 |
| 上一个匹配 | `Shift + Enter` | 跳转到上一个匹配项 |
| 关闭搜索 | `Esc` | 关闭搜索替换栏 |

### Markdown 快捷键

编辑器支持 Markdown 语法快捷输入：

| 输入 | 结果 |
|------|------|
| `#` + 空格 | 一级标题 |
| `##` + 空格 | 二级标题 |
| `###` + 空格 | 三级标题 |
| `**文字**` | **加粗** |
| `*文字*` | *斜体* |
| `` `代码` `` | 行内代码 |
| `- ` + 空格 | 无序列表 |
| `1.` + 空格 | 有序列表 |
| `> ` + 空格 | 引用块 |
| `---` | 分隔线 |
| `[文字](URL)` | 超链接 |
| `![描述](图片URL)` | 图片 |

## 导航快捷键

以下快捷键用于在不同页面之间导航。

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Alt + Left` | 返回 | 返回上一个访问的页面 |
| `Alt + Right` | 前进 | 前往下一个页面（在使用过返回后可用） |

### 页面切换

通过顶栏导航图标可以在主要页面间切换：

| 页面 | 入口 | 说明 |
|------|------|------|
| 工作台 | 顶栏第一个图标 | 快速记录页面 |
| 记录库 | 顶栏第二个图标 | 浏览和管理所有记录 |
| 设置 | 顶栏齿轮图标 | 应用设置页面 |

> **提示**：在编辑器中使用 `Ctrl + K` 命令面板是快速跳转到其他记录的最快方式，无需离开键盘。

## 跨平台说明

- Windows 和 Linux 通常使用 `Ctrl`。
- macOS 通常使用 `Command (⌘)` 替代 `Ctrl`。
- Windows 正式桌面应用复制后可以配合系统剪贴板历史记录使用 `Win + V`。
- macOS/Linux 没有统一的 Windows Clipboard History 面板，但复制粘贴仍使用平台可用的系统剪贴板能力。
- 复制成功、复制失败和粘贴成功都会显示提示，方便确认系统剪贴板是否可用。
