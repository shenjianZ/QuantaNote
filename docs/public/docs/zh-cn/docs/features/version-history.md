# 版本历史

QuantaNote 自动追踪每条记录的内容变更历史。每次编辑保存时，系统会创建一个版本快照，记录当时的完整内容。你可以随时查看历史版本、对比版本差异，以及恢复到之前的某个版本。

版本历史功能确保你的每一次编辑都有迹可循，即使误操作修改或删除了内容，也可以轻松找回。

## 自动版本创建

版本快照在以下情况下自动创建：

- **内容变更保存时**：当记录的内容发生变化并触发保存时，系统自动创建一个新版本
- **防抖机制**：连续编辑时不会为每次按键都创建版本，而是在防抖窗口结束后创建
- **完整快照**：每个版本保存当时的完整内容，而非增量差异

版本创建过程完全自动，无需手动操作。你只需要正常编辑和保存，系统会在后台维护版本历史。

### 版本保留

- 版本数据存储在本地 SQLite 数据库的 `versions` 表中
- 版本数量没有硬性上限，但建议定期清理不需要的旧版本
- 每个版本占用一定的存储空间（取决于内容长度）

## 版本面板

在文档编辑器中，你可以打开版本面板查看当前记录的版本历史：

1. 在文档编辑器中点击 **版本面板** 按钮
2. 版本面板在编辑器侧边展开
3. 版本列表按时间倒序排列，最新的版本在最上方

### 版本列表信息

每个版本条目显示以下信息：

| 信息项 | 说明 |
|--------|------|
| 创建时间 | 版本创建的时间戳 |
| 版本名称 | 可编辑的版本名称（默认为自动生成） |
| 版本描述 | 可编辑的版本描述（可选） |
| 内容摘要 | 版本内容的前若干字符预览 |

## 命名和描述

你可以为版本添加自定义名称和描述，帮助识别每个版本的变更内容：

- **编辑名称**：点击版本名称进入编辑模式，输入自定义名称后保存
- **编辑描述**：点击版本描述区域，输入对本次变更的简要说明
- **默认名称**：未手动设置名称时，系统使用时间戳作为默认名称

良好的命名和描述习惯可以让你在回溯历史时快速找到目标版本。例如，可以命名为"初稿"、"修订版"、"最终版"等。

## Diff 对比

版本历史支持选择两个版本进行内容差异对比（Diff），直观展示内容的变化：

1. 在版本面板中选择两个版本
2. 点击 **Diff 对比** 按钮打开对比视图
3. 对比视图使用 diff 库计算并展示两个版本之间的差异

### 对比视图说明

| 标记 | 含义 |
|------|------|
| 绿色高亮 | 新增的内容 |
| 红色高亮 | 删除的内容 |
| 无标记 | 未变化的内容 |

Diff 对比功能让你清楚地看到每次编辑的具体变化，方便确认修改是否正确。

## 恢复版本

如果你需要将记录恢复到之前的状态：

1. 在版本面板中找到目标版本
2. 点击 **恢复** 按钮
3. 确认恢复操作
4. 记录内容将替换为目标版本的内容

### 恢复注意事项

- 恢复操作会将当前内容替换为所选版本的内容
- 恢复前建议先检查版本差异，确认恢复目标正确
- 恢复操作本身也会触发一次版本保存，记录恢复前的内容
- 即使恢复后发现选错了版本，也可以通过版本历史回退

版本历史功能为你的内容编辑提供了完整的安全网，让你可以放心地修改和实验，而不必担心丢失重要内容。
