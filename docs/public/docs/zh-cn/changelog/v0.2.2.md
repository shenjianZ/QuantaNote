# v0.2.2

此版本聚焦发布与更新链路的可靠性，修复下载更新后签名校验失败的问题，并让更新错误在应用内呈现得更清晰。

## 修复

- 修复桌面端更新器公钥配置被占位符覆盖，导致下载更新后签名校验失败的问题。
- 更新关于页的更新错误提示，签名校验失败时显示明确原因，便于定位是发布包、manifest 还是本地更新配置异常。

## 影响范围

- 已安装用户可以继续通过应用内更新获取后续版本。
- 发布流程生成的更新包与更新 manifest 需要保持同一签名配置。
- 如果更新失败，用户可在关于页看到更具体的错误提示，而不是只有通用失败状态。
