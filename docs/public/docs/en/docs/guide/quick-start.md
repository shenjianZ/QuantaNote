# Quick Start

This guide will help you master the basics of QuantaNote in just 5 minutes. By the end, you will be comfortable creating, editing, organizing, and finding notes.

## Creating Your First Note

When you launch QuantaNote, you will see the **Workspace** page — your quick capture entry point.

1. In the input field in the center of the page, simply type your content.
2. When you are done, press `Ctrl + Enter` to save the note.
3. After saving, the note appears in the preview area below and is automatically added to your Library.

> **Tip**: The Workspace is ideal for quickly capturing ideas and short notes. For longer documents, you can open the note in the Library to access the full-screen editor.

The Workspace page supports Markdown live preview. You can use Markdown syntax in the input field, and the rendered result is displayed instantly below.

## Browsing the Library

Click **Library** in the top navigation bar to enter the note management page. This is where all your notes are collected, with multiple ways to browse and filter.

### Filter Tabs

The Library offers the following filter tabs at the top:

- **All** — Show all notes
- **Pinned** — Show only pinned notes
- **Favorites** — Show only notes marked as favorites

### Sort Options

Multiple sorting options are available:

- **By Updated Time** — Most recently updated notes first (default)
- **By Created Time** — Most recently created notes first
- **By Title** — Alphabetical order by title

### Note Actions

In the Library, you can perform the following actions on notes:

- **Pin / Unpin** — Keep important notes at the top
- **Favorite / Unfavorite** — Mark notes you love
- **Delete** — Remove unwanted notes (can be restored through version history)

## Editing Documents

Click any note in the Library, or double-click a note preview card in the Workspace, to open the **Document Editor** page.

### Title and Summary

- **Title**: Edit the note title at the top of the page. Clear titles help with search and identification later.
- **Summary**: Add a brief summary to your note, making it easy to scan in the Library list view.

### Editor Features

QuantaNote uses the Vditor editor for a WYSIWYG Markdown editing experience:

- **Toolbar**: Common formatting buttons at the top of the editor (bold, italic, headings, lists, code blocks, links, etc.)
- **Live Preview**: Markdown formatting is rendered in real time as you type
- **Keyboard Shortcuts**: Supports common Markdown shortcuts (e.g., `Ctrl+B` for bold, `Ctrl+I` for italic)
- **Auto-Save**: Content is saved automatically — no manual action needed

### Code Blocks and Math Formulas

You can insert code blocks and math formulas in your notes:

- Use triple backticks `` ``` `` to wrap code blocks with syntax highlighting
- Use `$$` to wrap math formulas (rendered with KaTeX)

## Using Tags

Tags are the core way to organize notes in QuantaNote. By assigning tags to notes, you can flexibly categorize and filter your content.

### Creating Tags

1. Open the **Tag Manager** (accessible from the sidebar or settings page).
2. Click the "New Tag" button.
3. Enter a tag name and choose an identifying color.
4. Confirm to create the tag.

### Assigning Tags to Notes

- While editing a note, use the tag picker to add one or more tags to the current note.
- In the Library, you can select multiple notes and add tags in bulk.

### Filtering by Tag

- In the Library sidebar, click a tag name to filter and display all notes with that tag.
- Supports multi-tag combination filtering.

## Searching

QuantaNote provides powerful full-text search to help you quickly find what you need among a large collection of notes.

### Command Palette

Press `Ctrl + K` to open the global command palette. Type a keyword in the search box to instantly search across all note titles and content.

### Full-Text Search Features

- **Chinese & English Support**: Powered by the FTS5 engine with Chinese and English tokenization
- **Millisecond Response**: Search results appear instantly, even with thousands of notes
- **Match Highlighting**: Matching keywords are highlighted in the search results

### Search Tips

- Entering multiple keywords matches notes that contain all of those keywords
- Search matches both note titles and body content
- Results are ranked by relevance
