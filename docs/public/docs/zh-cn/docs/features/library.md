# 记录库

记录库是 QuantaNote 中管理所有笔记记录的中心。你在这里可以浏览、筛选、搜索和管理所有已保存的记录。记录库以卡片视图呈现每条记录的关键信息，让你快速定位目标内容。

## 记录列表

记录库采用卡片视图展示所有记录，每张卡片包含以下信息：

- **标题**：记录的标题文本，通常从内容第一行自动提取
- **摘要**：记录内容的简要预览，截取前若干字符展示
- **标签**：记录关联的彩色标签，以标签徽章形式显示
- **时间**：显示记录的更新时间或创建时间，采用相对时间格式（如"3分钟前"、"昨天"）

卡片视图支持滚动浏览，列表按指定排序方式排列。

## 筛选标签

记录库顶部提供了快捷筛选选项，帮助你快速切换查看不同类型的记录：

| 筛选器 | 说明 |
|--------|------|
| 全部 | 显示所有记录，不限条件 |
| 置顶 | 仅显示被置顶的记录 |
| 收藏 | 仅显示被标记为收藏的记录 |

切换筛选器后，列表会立即刷新显示对应结果。

## 标签过滤

除了快捷筛选外，记录库支持按特定标签进行过滤：

- 点击标签过滤区域，会展开所有可用标签列表
- 选择一个标签后，列表仅显示关联了该标签的记录
- 标签以颜色编码显示，方便视觉区分
- 可以取消标签过滤以恢复显示全部记录

## 笔记属性过滤

如果笔记正文包含 Frontmatter 属性，筛选面板还可以按状态和优先级过滤记录。属性过滤可以和全部、置顶、收藏、标签以及搜索条件组合使用。

筛选面板还支持按记录类型、更新时间、是否有标签和是否包含附件过滤；状态中的“未完成”会排除已完成和已归档记录。

## 智能集合和保存搜索

记录库顶部提供内置智能集合：最近修改、未分类、收藏和未完成。智能集合是动态条件，每次打开或点击时都会根据当前记录重新计算。

在筛选面板中输入名称并点击 **保存搜索**，即可保存当前的关键词、标签、类型、时间、状态、优先级、附件和搜索范围条件。保存的搜索会写入应用设置，重启应用后仍然可用；点击名称可以重新应用条件，点击旁边的关闭按钮可以删除它。

## 排序

记录库支持多种排序方式，满足不同的浏览需求：

| 排序方式 | 说明 |
|----------|------|
| 按更新时间 | 最近更新的记录排在最前（默认排序） |
| 按创建时间 | 最近创建的记录排在最前 |
| 按标题 | 按标题字母顺序排列 |
| 按优先级 | 高优先级记录排在前面 |
| 按截止日期 | 有截止日期的记录按日期从早到晚排列，没有截止日期的记录排在后面 |

排序选项可以在记录库界面中切换，切换后列表立即重新排列。

## 阅读抽屉

记录库内置了阅读抽屉功能，无需打开文档编辑器即可预览记录内容：

- **侧边抽屉**：点击记录卡片后，从右侧滑出阅读抽屉
- **Markdown 渲染**：抽屉内将记录内容以 Markdown 格式渲染展示，支持标题、列表、代码块、表格等
- **笔记链接**：支持点击 `[[笔记名称]]` 打开目标笔记，并在正文下方查看正向链接、反向链接和关系图
- **快速预览**：在不离开记录库页面的情况下快速阅读记录全文
- **关闭抽屉**：点击关闭按钮或点击外部区域即可关闭抽屉

阅读抽屉适合快速浏览记录内容，当你需要编辑时可以进一步进入文档编辑器。

## 记录操作

每条记录支持以下操作：

| 操作 | 说明 |
|------|------|
| 编辑 | 打开文档编辑器，进入全屏编辑模式 |
| 删除 | 删除该记录（不可恢复，请谨慎操作） |
| 置顶 | 将记录固定在列表顶部，方便快速访问 |
| 取消置顶 | 取消置顶状态，恢复原始排序位置 |
| 收藏 | 将记录标记为收藏，可通过筛选器快速找到 |
| 取消收藏 | 取消收藏标记 |
| 复制内容 | 将记录的完整内容复制到系统剪贴板，并显示结果提示 |
| 管理标签 | 打开标签选择器，为记录添加或移除标签 |
| 管理附件 | 打开附件管理器，查看和上传附件 |

操作入口通常在记录卡片上或阅读抽屉的操作菜单中。

Windows 正式桌面应用复制后可以在开启系统剪贴板历史记录时使用 `Win + V` 查看。macOS/Linux 没有同等的 Windows 面板，但仍会使用平台可用的剪贴板能力。

## 新建记录

在记录库页面也可以创建新记录：

- 点击 **新建笔记** 按钮后，可以在模板选择器中选择空白笔记或内置/自定义模板
- 选择后新记录会自动进入文档编辑器，方便立即开始编辑
- 选择模板时，模板名称会作为新记录的初始标题；空白笔记仍使用默认标题，可在编辑器中修改

此外，通过工作台的快速记录功能保存的内容也会自动出现在记录库中。
