# 介绍 QuantaNote

## 什么是 QuantaNote

QuantaNote 是一款**本地优先**的桌面信息管理工具，基于 [Tauri 2.0](https://tauri.app/) 框架构建。它将 Rust 后端的高性能与 React 前端的灵活性相结合，为你提供一个轻量、快速、安全的笔记与知识管理体验。

与大多数需要云端账户和网络连接的笔记应用不同，QuantaNote 的所有数据都存储在你本地设备的 SQLite 数据库中。这意味着你可以完全掌控自己的数据，无需担心隐私泄露或服务停机。

QuantaNote 的数据目录位于 `~/.quantanote/`（Windows 系统为 `%USERPROFILE%\.quantanote\`），核心数据库文件为 `quanta_note.sqlite`，采用 WAL 模式以确保高性能的读写操作。

## 为什么选择本地优先

「本地优先」不仅是一种技术选择，更是一种数据哲学：

- **数据所有权** — 你的笔记、想法和知识完全属于你。没有任何第三方服务器可以访问或控制你的数据。你可以随时导出、备份或迁移。

- **离线能力** — 无论身处何地，无论网络状况如何，QuantaNote 始终可用。在飞机上、地铁里、网络不稳定的环境中，你都可以正常记录和编辑。

- **隐私保护** — 数据不经过任何第三方服务器传输或存储，从根本上杜绝了数据泄露的风险。你的隐私由你自己守护。

- **极致速度** — 本地 SQLite 数据库提供毫秒级的读写性能，配合 FTS5 全文搜索索引，即使在大量数据下也能保持流畅的体验。

## 核心功能

QuantaNote 提供了一套完整的笔记与信息管理功能：

### Markdown 编辑

基于 [Vditor](https://github.com/Vanessa219/vditor) 编辑器，提供所见即所得的 Markdown 编辑体验。支持实时预览、代码语法高亮、数学公式（KaTeX）、流程图、表格等丰富的内容格式。无论是简单的备忘还是复杂的技术文档，都能轻松应对。

### 全文搜索

基于 SQLite FTS5 引擎构建的全文搜索系统，支持中英文分词，可以在毫秒级别从数千条记录中找到你需要的内容。通过 `Ctrl+K` 快捷键随时唤起搜索面板。

### 标签管理

为笔记创建带有颜色标识的标签，通过标签对笔记进行分类和筛选。支持多标签关联，灵活组织你的知识体系。

### 版本历史

自动记录每次编辑操作的历史版本，支持版本间的差异对比和一键回滚。误操作不再可怕，你可以随时恢复到之前的任何状态。

### 附件管理

支持在笔记中嵌入图片、文件等附件。附件与笔记关联存储，方便管理和查找。

### 多设备同步

支持在多台设备之间同步数据，内置三方差异比较（Three-way Diff）算法和冲突解决机制，确保在多设备编辑场景下数据的一致性。

### 自动备份

定期自动备份你的数据，也支持手动导出和导入，确保数据安全万无一失。

## 适用场景

QuantaNote 适用于各种个人知识和信息管理场景：

- **个人笔记** — 日常记录、灵感捕捉、会议纪要、学习笔记。快速记录页面让你随时随地记录想法。
- **知识管理** — 通过标签系统和全文搜索，构建和管理个人知识库。支持 Markdown 格式，适合撰写结构化的知识文档。
- **任务追踪** — 结合置顶、收藏和标签功能，管理和追踪待办事项和项目进度。
- **代码片段** — 利用 Markdown 代码块和语法高亮，收集和组织常用的代码片段和技术参考资料。
