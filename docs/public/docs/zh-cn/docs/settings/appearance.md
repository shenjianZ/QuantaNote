# 外观设置

外观设置让你自定义 QuantaNote 的视觉风格，包括主题模式、强调色和界面语言。所有外观设置变更会立即生效，无需重启应用。

## 主题

QuantaNote 提供三种主题模式，通过顶部设置页面的主题按钮组进行切换：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **跟随系统** | 自动跟随操作系统的深色/浅色模式设置 | 推荐大多数用户使用，自动适应环境光线变化 |
| **亮色** | 始终使用浅色背景主题 | 适合光线充足的环境，或个人偏好浅色界面 |
| **暗色** | 始终使用深色背景主题 | 适合夜间使用或低光环境，减少眼睛疲劳 |

### 切换方式

在设置页面的「外观」版块中，点击对应的主题按钮即可切换：

- 点击 **跟随系统**（电脑图标）按钮，应用将自动匹配系统主题
- 点击 **亮色**（太阳图标）按钮，强制使用浅色主题
- 点击 **暗色**（月亮图标）按钮，强制使用深色主题

### 技术说明

主题通过 `data-theme` HTML 属性实现切换，CSS 变量定义在 `styles/themes.css` 中：

- `--app-bg`：应用背景色
- `--paper`：内容区域背景色
- `--text`：主文本颜色
- `--muted`：次要文本颜色
- `--line`：边框颜色
- `--field`：输入框背景色
- `--hover`：悬停背景色
- `--accent`：强调色
- `--accent-soft`：强调色浅色变体

### 自定义颜色

如果预设颜色不能满足你的需求，可以通过颜色选择器添加自定义强调色：

1. 点击预设颜色区域下方的 **+** 按钮
2. 在弹出的颜色选择器中选择你喜欢的颜色
3. 为颜色输入一个名称
4. 点击确认，自定义颜色会立即添加到颜色列表中

已添加的自定义颜色会显示在「自定义」区域，鼠标悬停在自定义颜色上时会出现删除按钮，点击即可移除。

## 语言

QuantaNote 支持中文和英文两种界面语言。

| 语言 | 代码 | 说明 |
|------|------|------|
| 中文 | `zh-CN` | 简体中文界面（默认） |
| English | `en` | 英文界面 |

### 切换方式

在设置页面的「外观」版块底部，找到「语言」选项，通过下拉选择器切换语言。语言切换会立即生效，所有界面文本会自动更新为对应语言。

> **提示**：语言设置也会影响日期格式、时间显示等本地化内容。
