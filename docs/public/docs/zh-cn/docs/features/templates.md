# 模板

模板用于把重复的 Markdown 结构保存下来，在新建笔记时快速开始。QuantaNote 提供内置模板，也支持创建自己的模板。

## 选择模板

在记录库、顶部新建入口、命令面板或系统托盘选择新建笔记后，会先打开模板选择器：

- **空白笔记**：创建没有正文的笔记。
- **内置模板**：选择每日记录、会议记录、阅读笔记或项目记录。
- **我的模板**：使用已保存的自定义模板。

选择后会创建笔记并进入编辑器。模板名称会作为新笔记的初始标题，正文中的 `{{date}}` 和 `{{time}}` 会在创建时替换为当前日期和时间。

工作台的快速记录仍然直接保存输入内容，不会打断快速捕获流程。

## 管理自定义模板

在模板选择器中点击 **管理模板**，可以：

1. 点击 **新建模板**，填写名称、说明和 Markdown 正文。
2. 编辑已有的自定义模板，修改后保存。
3. 复制内置模板或自定义模板，生成一份可编辑副本。
4. 删除自定义模板。删除需要再次点击确认。

内置模板是应用提供的只读内容，不能直接修改或删除；先复制后即可按自己的习惯调整。

## 数据保存范围

自定义模板保存在本地 QuantaNote 数据库的 `templates` 表中，会随应用数据保留。内置模板来自应用的中英文资源，不占用用户模板数据，也不会被误删。当前模板属于本机编辑辅助数据，不参与笔记正文的同步。
