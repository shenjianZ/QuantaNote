# 快捷键

QuantaNote 使用 `Mod` 表示当前平台的主修饰键：Windows/Linux 是 `Ctrl`，macOS 是 `Command (⌘)`。快捷键可以在“设置 → 快捷键”中查看、录入、清除或恢复默认值。

## 应用快捷键

以下快捷键由 QuantaNote 处理。它们在输入框、文本域和编辑器正文获得焦点时不会抢占文字输入。

| 默认快捷键 | 功能 | 生效范围 |
|---|---|---|
| `Mod + K` | 打开/关闭命令面板 | 全局（编辑器正文内不触发） |
| `Mod + N` | 新建笔记 | 全局（可编辑区域内不触发） |
| `Mod + ,` | 打开设置 | 全局（可编辑区域内不触发） |
| `Mod + Enter` | 快速保存工作台内容 | 工作台 |
| `Mod + S` | 保存当前笔记 | 文档编辑器 |
| `Mod + F` | 查找 | 文档编辑器 |
| `Mod + H` | 查找并替换 | 文档编辑器 |

## 命令面板

按 `Mod + K` 打开命令面板。面板同时提供笔记搜索和当前页面可用的命令：

- 新建笔记、打开设置。
- 在文档编辑器中保存笔记、插入图片、管理附件、打开版本历史。
- 在文档编辑器或记录库中复制当前笔记。
- 输入关键词后按方向键和 `Enter` 选择；按 `Esc` 关闭。

## 编辑器快捷键

文档编辑器由 Vditor 提供通用编辑操作，QuantaNote 负责保存和查找替换：

| 快捷键 | 功能 |
|---|---|
| `Mod + S` | 立即保存标题、摘要和正文；编辑器仍会自动保存 |
| `Mod + F` | 打开查找栏 |
| `Mod + H` | 打开查找替换栏 |
| `Mod + B` | 加粗 |
| `Mod + I` | 斜体 |
| `Mod + D` | 删除线 |
| `Mod + Z` | 撤销 |
| `Mod + Shift + Z` | 重做 |
| `Mod + A` | 全选 |
| `Mod + C` / `Mod + X` / `Mod + V` | 复制 / 剪切 / 粘贴 |
| `Tab` / `Shift + Tab` | 列表缩进 / 反向缩进 |

在查找栏中，`Enter` 跳到下一个匹配，`Shift + Enter` 跳到上一个匹配，`Esc` 关闭查找栏。编辑器正文内的 `Mod + K`、`Mod + N` 和 `Mod + ,` 会保留给文本编辑，不会打开全局操作。

## 自定义和冲突检测

1. 打开“设置 → 快捷键”。
2. 点击要修改的快捷键按钮，再按下包含修饰键的组合。
3. 如果两个命令使用同一组合，页面会立即显示冲突的命令名称。
4. 可以点击“清除”禁用某个应用快捷键，或点击“恢复默认”恢复全部默认值。

Vditor 的编辑快捷键不作为应用命令重复注册；这样可以避免自定义全局命令覆盖正文编辑操作。录入快捷键时，单独按字母或方向键不会被保存。
