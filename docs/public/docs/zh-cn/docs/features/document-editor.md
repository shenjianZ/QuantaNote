# 文档编辑器

文档编辑器提供全屏沉浸式的编辑体验。当你需要深入编辑一条记录时，从记录库进入文档编辑器，可以获得更大的编辑空间和更完整的编辑功能。

文档编辑器基于 Vditor Markdown 编辑器，采用即时渲染（IR）模式，兼顾 Markdown 纯文本编辑与所见即所得的预览体验。

## 标题和摘要

文档编辑器顶部提供了可编辑的标题和摘要字段：

- **标题字段**：显示当前记录的标题，可以直接点击编辑修改
- **摘要字段**：显示记录的摘要信息，可以手动填写或编辑
- 标题修改后会实时同步到记录库的卡片视图中

标题和摘要作为记录的元数据，帮助你快速了解记录的核心内容，也便于在搜索和列表中识别。

## Vditor 编辑器

编辑器主体使用 Vditor 提供 Markdown 编辑能力：

- **完整工具栏**：包含标题、加粗、斜体、删除线、列表、引用、代码块、链接、表格等所有常用格式化按钮
- **多种编辑模式**：支持 IR（即时渲染）、SV（分屏预览）、WYSIWYG（所见即所得）等模式
- **IR 模式**（默认）：输入 Markdown 语法后即时渲染为格式化文本，同时保留语法的可编辑性
- **代码高亮**：支持多种编程语言的语法高亮显示
- **公式支持**：支持 KaTeX 数学公式渲染

## 自动保存

文档编辑器内置了防抖自动保存机制，确保你的编辑内容不会丢失：

- **防抖机制**：内容变更后等待一段短暂时间（通常 1-2 秒），如果没有新的变更则自动触发保存
- **状态指示**：编辑器会显示当前保存状态，让你了解内容是否已保存
- **无感保存**：自动保存在后台执行，不会打断你的编辑流程
- **异常处理**：如果保存失败，会显示错误提示，保留编辑内容不丢失

## 收藏切换

文档编辑器中可以快速切换记录的收藏状态：

- **星标按钮**：编辑器界面提供收藏星标图标按钮
- **一键切换**：点击星标按钮即可在收藏/取消收藏之间切换
- **视觉反馈**：收藏状态下星标会高亮显示，未收藏则为空心图标
- 收藏后的记录可以在记录库中通过"收藏"筛选器快速找到

## 版本面板

文档编辑器内置了版本历史面板，方便你追踪和回顾内容的变更历史：

- **面板位置**：版本面板在编辑器侧边展开
- **版本列表**：显示当前记录的所有历史版本，按时间倒序排列
- **版本信息**：每个版本条目显示创建时间和可选的名称、描述
- **版本操作**：支持查看版本详情、对比版本差异、恢复到指定版本

详细的版本历史功能请参考 [版本历史](./version-history) 文档。

## 返回导航

编辑完成后，你可以通过返回导航回到记录库：

- **返回箭头**：编辑器左上角提供返回箭头按钮
- **快捷返回**：点击返回箭头即可返回记录库页面
- **自动保存**：返回前如有未保存的内容会自动保存，无需手动操作

文档编辑器的设计目标是提供一个专注、高效的编辑环境，让你能够全身心投入内容创作。
