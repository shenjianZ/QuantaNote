# 附件

QuantaNote 支持为记录关联文件附件，让你可以在笔记中保存和引用各种类型的文件。无论是图片、文档还是音视频文件，都可以作为附件与记录关联管理。

## 上传文件

为记录上传附件的操作流程：

1. 在记录操作菜单中点击 **管理附件**，打开附件管理器弹窗
2. 点击上传按钮，打开系统文件选择对话框
3. 选择一个或多个文件，确认上传
4. 上传完成后，附件自动关联到当前记录

上传的文件会被复制到 QuantaNote 的本地数据目录中，原始文件不受影响。

### 支持的文件格式

附件功能不限制文件格式，你可以上传任何类型的文件。但不同类型的文件在附件管理器中的预览能力有所不同。

## 支持的预览类型

附件管理器根据文件类型提供不同的预览能力：

| 文件类型 | 支持格式 | 预览方式 |
|----------|----------|----------|
| 图片 | `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.svg`, `.webp` | 直接在弹窗中显示图片缩略图和预览 |
| 音频 | `.mp3`, `.wav`, `.ogg`, `.m4a`, `.flac` | 内置音频播放器，支持播放/暂停和进度控制 |
| 视频 | `.mp4`, `.webm`, `.mov`, `.avi` | 内置视频播放器，支持播放控制和音量调节 |
| PDF | `.pdf` | 内置 PDF 查看器，支持翻页浏览 |
| 文本 | `.txt`, `.md`, `.json`, `.csv`, `.xml`, `.log` | 以文本形式显示文件内容 |
| 其他 | 所有其他格式 | 显示文件名、大小等基本信息，不支持预览 |

预览功能帮助你在不离开 QuantaNote 的情况下快速查看附件内容。

## 管理附件

附件管理器弹窗提供了完整的附件管理功能：

### 查看附件列表

- 所有附件以列表形式显示
- 每个附件条目显示文件名、文件大小和文件类型
- 点击附件可以在右侧预览区域查看内容

### 删除附件

- 在附件列表中选择要删除的附件
- 点击删除按钮移除附件
- 删除操作会同时移除文件关联记录和本地文件

> **注意**：删除附件操作不可撤销，请确认后再执行。

### 附件信息

附件管理器中每条附件显示以下信息：

| 信息项 | 说明 |
|--------|------|
| 文件名 | 上传时的原始文件名 |
| 文件大小 | 以 KB 或 MB 为单位显示文件体积 |
| 文件类型 | 文件的 MIME 类型或扩展名 |
| 上传时间 | 文件上传的时间戳 |

## 存储位置

附件文件存储在 QuantaNote 的本地数据目录中，按记录 ID 分组存放：

```
~/.quantanote/attachments/{item_id}/
```

其中 `{item_id}` 是记录的唯一标识符（UUID 格式）。

### 存储说明

- **文件复制**：上传附件时，文件会被复制到上述目录，原始文件不会被移动或修改
- **独立存储**：每条记录的附件存放在独立的子目录中，互不影响
- **随记录删除**：删除记录时，关联的附件文件会一并删除
- **备份建议**：如需备份，建议直接备份整个 `~/.quantanote/` 目录

### Windows 路径

在 Windows 系统中，数据目录位于：

```
%USERPROFILE%\.quantanote\attachments\{item_id}\
```

附件功能让你的笔记不再局限于纯文本，可以轻松关联和管理多种类型的参考文件。
