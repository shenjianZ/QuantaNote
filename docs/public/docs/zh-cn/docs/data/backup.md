# 备份

QuantaNote 提供灵活的备份机制，包括自动定时备份和手动即时备份。备份数据以 SQLite 数据库副本的形式保存，确保你的笔记数据在任何意外情况下都可以恢复。

## 自动备份

自动备份功能可以在设定的时间间隔自动创建数据库备份，无需手动干预。

**启用自动备份：**

1. 打开 **设置 > 数据管理** 页面
2. 找到"自动备份"选项
3. 开启自动备份开关
4. 配置备份参数（见下方"备份配置"部分）

启用后，QuantaNote 会在应用运行期间按照设定的时间间隔自动创建备份。如果应用未运行，则不会触发备份任务。

> **注意**：自动备份仅在应用运行时生效。如果你很少打开 QuantaNote，建议同时定期进行手动备份。

## 备份配置

自动备份提供以下可配置参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 备份间隔 | 7 天 | 两次自动备份之间的时间间隔 |
| 最大备份数 | 10 | 保留的备份文件最大数量 |
| 过期天数 | 30 天 | 超过此天数的备份将被自动清理 |

**备份间隔**：可设置为 1-30 天之间的任意值。间隔越短，备份越频繁，但占用更多磁盘空间。

**最大备份数**：当备份文件数量超过此限制时，系统会自动删除最旧的备份文件。

**过期天数**：即使备份数量未达到上限，超过过期天数的备份也会被自动清理。

> **提示**：建议根据你的使用频率和数据重要性来调整这些参数。对于日常重度使用者，建议间隔设为 1-3 天，最大备份数设为 15-20。

## 手动备份

除了自动备份外，你可以随时手动创建备份：

1. 打开 **设置 > 数据管理** 页面
2. 点击"立即备份"按钮
3. 系统会立即创建一个备份文件

手动备份不受自动备份的间隔限制和数量限制影响。它会立即执行并以时间戳命名保存。

手动备份适用于以下场景：

- 在进行大量编辑操作之前
- 在导入数据之前作为安全措施
- 在执行系统更新或迁移之前
- 任何你觉得需要额外保护的重要时刻

## 备份管理器

备份管理器提供了一个可视化界面来管理所有备份文件。

**功能一览：**

- **查看备份列表** — 以时间倒序显示所有备份，最新的在最上方
- **查看详情** — 每个备份显示创建时间、文件大小等信息
- **删除备份** — 可以手动删除不需要的备份文件以释放磁盘空间
- **批量清理** — 一键清理过期或多余的备份

**备份列表信息：**

| 字段 | 说明 |
|------|------|
| 文件名 | 自动生成，包含时间戳，如 `backup_20260503_143022.db` |
| 创建时间 | 备份创建的精确时间 |
| 文件大小 | 备份文件占用的磁盘空间 |
| 操作 | 删除按钮 |

> **注意**：删除备份操作不可撤销。删除前请确认你不再需要该备份。

## 存储位置

所有备份文件保存在以下目录：

```
~/.quantanote/backups/
```

在 Windows 系统上，完整路径为：

```
%USERPROFILE%\.quantanote\backups\
```

**备份文件命名规则：**

```
backup_YYYYMMDD_HHmmss.db
```

例如：`backup_20260503_143022.db` 表示 2026 年 5 月 3 日 14:30:22 创建的备份。

**备份文件说明：**

- 备份文件是完整的 SQLite 数据库副本
- 可以直接用于替换主数据库以恢复数据
- 文件大小与实际数据量相关，通常小于导出的 ZIP 文件
- 备份过程使用 SQLite 的备份 API，不会锁定数据库，不影响正常使用

> **建议**：对于特别重要的数据，考虑将备份文件复制到外部存储设备或云存储中，以防止设备故障导致备份和原始数据同时丢失。
