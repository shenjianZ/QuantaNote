# 命令面板

命令面板是 QuantaNote 提供的全局快速访问工具。通过 `Ctrl + K` 快捷键，你可以在任何页面快速唤起命令面板，输入关键词搜索所有记录，并直接导航到目标页面。

命令面板的设计灵感来自于 VS Code 的命令面板，目标是减少操作步骤，让你以键盘为中心快速完成常见操作。

## 打开方式

通过以下方式打开命令面板：

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 打开命令面板 | `Ctrl + K` | 在任何页面按下此快捷键即可打开 |
| 关闭命令面板 | `Esc` | 按下 Esc 键或点击面板外部区域关闭 |

打开后，命令面板以浮层形式显示在页面中央，包含一个搜索输入框和结果列表。

## 搜索

在命令面板中输入关键词即可搜索所有记录：

1. 按 `Ctrl + K` 打开命令面板
2. 在输入框中键入搜索关键词
3. 搜索结果实时更新显示在输入框下方

### 搜索特点

- **实时搜索**：输入关键词后立即显示匹配结果，无需按回车
- **全库搜索**：搜索范围覆盖所有记录的标题、内容和摘要
- **模糊匹配**：支持部分关键词匹配，不需要输入完整标题
- **快速响应**：搜索基于 FTS5 索引，响应速度极快

### 搜索结果展示

每个搜索结果条目显示以下信息：

| 信息项 | 说明 |
|--------|------|
| 标题 | 记录的标题文本 |
| 类型图标 | 记录类型的视觉标识 |
| 内容摘要 | 匹配内容的简要预览 |
| 标签 | 记录关联的彩色标签 |

## 导航

命令面板的核心功能是快速导航：

### 直接打开记录

- 点击搜索结果中的任意条目，直接打开对应的记录
- 记录会在文档编辑器中以全屏模式打开，可以立即开始编辑
- 打开记录后命令面板自动关闭

### 显示最近记录

- 打开命令面板时，如果未输入任何关键词，会显示最近编辑的记录列表
- 方便你快速返回最近工作过的记录
- 列表按最后编辑时间倒序排列

### 导航流程

```
Ctrl + K → 输入关键词 → 查看结果 → 点击目标 → 打开记录
```

整个过程只需要几次键盘操作即可完成，无需手动切换页面或在记录库中翻找。

## 使用场景

命令面板在以下场景中特别有用：

| 场景 | 说明 |
|------|------|
| 快速查找 | 当你记不清某条记录在哪个分类时，通过关键词快速定位 |
| 频繁切换 | 需要在多条记录之间频繁切换时，用键盘操作比鼠标更高效 |
| 最近记录 | 打开面板即可看到最近编辑的记录，一键返回继续工作 |
| 键盘工作流 | 习惯键盘操作的用户可以全程不碰鼠标完成搜索和导航 |

命令面板是提升 QuantaNote 使用效率的关键工具，建议将 `Ctrl + K` 作为你的日常快捷键习惯。
