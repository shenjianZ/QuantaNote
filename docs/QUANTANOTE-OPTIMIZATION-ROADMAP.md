# QuantaNote 优化与功能路线图

> 目标：以“数据可信、编辑稳定、检索高效、知识可扩展”为顺序持续优化 QuantaNote。
>
> 维护方式：每完成一个任务，将对应的 `[ ]` 改为 `[x]`，并在任务下补充完成日期、修改范围和验证结果。没有经过测试或实际验证的项目不要标记完成。

## 当前状态

QuantaNote 已经具备比较完整的本地笔记软件基础：Markdown 编辑器、图片和附件、搜索、标签、版本、导入导出、自动备份、同步、系统托盘、主题和中英文文档等。

目前的主要问题不是基础功能数量不足，而是数据生命周期、异常恢复和大数据量下的稳定性还需要加强。因此，新增功能应服从以下优先级：

1. 先保证数据不会残留、丢失或无法恢复。
2. 再提升编辑器、搜索和同步的日常使用体验。
3. 最后扩展双向链接、模板、每日笔记等知识管理能力。
