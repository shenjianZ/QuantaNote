# v0.2.2

This release focuses on release and updater reliability. It fixes a signature verification failure after downloading desktop updates and makes update failures clearer in the app.

## Fixed

- Fixed the desktop updater public key configuration being overwritten by a placeholder, which caused downloaded updates to fail signature verification.
- Improved update error messages on the About page so signature verification failures show a concrete reason instead of a generic failure state.

## Impact

- Installed users can continue using in-app updates for later versions.
- Release packages and updater manifests must use the same signing configuration.
- When an update fails, the About page now gives a more actionable error message for diagnosing package, manifest, or local updater configuration issues.
