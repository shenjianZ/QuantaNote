# User Guide

Welcome to the QuantaNote user guide. This guide will walk you through everything you need to know, from setting up QuantaNote to mastering its features.

Whether you are trying QuantaNote for the first time or looking to dive deeper into a specific feature, you will find what you need in the sections below. We recommend reading them in order for a systematic understanding.

If you are already familiar with the basics, feel free to jump directly to the section that interests you.

## Sections

1. **[Introduction](/docs/guide/introduction)**

   Learn about QuantaNote's positioning, design philosophy, and core features. In this section, you will discover:

   - What QuantaNote is and what it can do for you
   - Why "local-first" matters for data management
   - An overview of QuantaNote's core features
   - Typical use cases where QuantaNote excels

   If you are still evaluating whether QuantaNote is the right tool for you, start here.

2. **[Installation](/docs/guide/installation)**

   Download and install QuantaNote. Includes detailed installation steps for Windows, macOS, and Linux, along with notes on first-time setup:

   - System requirements and compatibility
   - Platform-specific installation methods (installer, portable, AppImage)
   - Automatic initialization on first launch
   - How to uninstall and clean up the data directory

3. **[Quick Start](/docs/guide/quick-start)**

   Learn the basics in 5 minutes:

   - Create your first note in the Workspace
   - Browse, filter, and sort in the Library
   - Write and format content in the Document Editor
   - Create tags and organize your notes
   - Use global search to quickly find content

   Ideal for users who want to get started right away.

## Reading Suggestions

- **New Users**: We recommend starting with "Introduction" and reading through to "Quick Start" in order, then diving right into using QuantaNote.
- **Experienced Users**: You can jump directly to "Quick Start" for a refresher, or browse the [Feature Deep Dives](/docs/features/data) for advanced capabilities.
- **Developers**: If you want to contribute or extend QuantaNote, please refer to the [Developer Documentation](/docs/developer/architecture).

## Need Help?

If you encounter any issues while using QuantaNote, here are ways to get help:

- Submit an issue on [GitHub Issues](https://github.com/shenjianZ/QuantaNote/issues)
- Check the [Changelog](/changelog) for version updates and changes
