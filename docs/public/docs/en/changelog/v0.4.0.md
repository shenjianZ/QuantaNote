# v0.4.0

Release date: 2026-08-19

## Added

- Content-width control and a document outline for long documents and wide tables.
- Native Windows clipboard integration with copy and paste success/failure feedback.
- Table insertion and adjustment panels for row count, column count, and alignment.
- Mermaid, Flowchart, math, footnote, definition-list, and sanitized HTML rendering.
- Bilingual installation, usage, troubleshooting, and release documentation.

## Changed

- The summary field now has a fixed size so long summaries do not expand the layout.
- The table button shows “Insert table” or “Adjust table” based on the caret position.
- Editor scrolling and chart rendering remain stable without repeated initialization or flicker.
- Release CI validates versions, signatures, assets, and the updater manifest.

## Fixed

- Fixed table insertion losing the caret when the table panel was clicked.
- Fixed existing tables being unable to adjust their properties.
- Fixed Windows Clipboard History missing some copied content.
- Fixed missing chart runtime assets in packaged builds.

## Platform Compatibility

- The packaged Windows app uses the native clipboard path and supports `Win + V`.
- macOS and Linux use the clipboard APIs available on each platform and do not require Windows Clipboard History.
- Android releases provide an ARM64 APK.
