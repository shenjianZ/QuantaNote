# v0.4.0

发布日期：2026-08-19

## 新增

- 内容宽度控制和文档大纲，改善长文档与宽表格阅读体验。
- Windows 原生剪贴板支持，以及复制/粘贴成功和失败提示。
- 表格插入与已有表格调整面板，支持行数、列数和列对齐。
- Mermaid、Flowchart、数学公式、脚注、定义列表和安全 HTML 渲染。
- 中英文安装、使用、故障排查和发布文档。

## 改进

- 摘要输入框固定尺寸，避免长摘要撑开布局。
- 表格按钮根据光标位置显示“插入表格”或“调整表格”。
- 编辑器滚动和图表渲染保持稳定，减少重复初始化和闪烁。
- 发布 CI 增加版本、签名、资产和自动更新清单检查。

## 修复

- 修复表格面板点击后光标丢失导致无法插入表格的问题。
- 修复已有表格无法调整属性的问题。
- 修复 Windows Clipboard History 无法识别部分复制内容的问题。
- 修复正式构建中图表运行时资源缺失的问题。

## 平台兼容

- Windows 正式应用支持原生剪贴板和 `Win + V`。
- macOS/Linux 使用平台可用的剪贴板 API，不要求存在 Windows Clipboard History。
- Android 发布 ARM64 APK。
