# 设置

QuantaNote 提供了丰富的个性化配置选项，让你可以根据自己的使用习惯和偏好定制应用。设置页面通过左侧导航菜单分为多个版块，点击即可切换到对应配置页面。

## 设置版块一览

| 版块 | 说明 |
|------|------|
| [外观设置](./appearance) | 配置主题模式（亮色/暗色/跟随系统）、强调色（12 种预设 + 自定义颜色）、界面语言 |
| [字体设置](./fonts) | 选择 UI 字体、等宽字体，调整字号（14-18px），实时预览效果 |
| [系统集成](./system) | 窗口行为（最小化到托盘、关闭时继续运行）、开机自启、系统托盘菜单 |
| [诊断工具](./diagnostics) | SQL 日志配置、日志文件管理、数据库信息查看与 VACUUM 优化 |
| [快捷键](./shortcuts) | 全局快捷键、工作台快捷键、编辑器快捷键和导航快捷键一览 |

## 如何访问设置

1. 点击顶部导航栏右侧的 **设置** 图标
2. 从左侧菜单选择你要调整的设置类别
3. 所有设置更改会 **立即生效** 并自动保存

## 设置存储

所有设置保存在本地 SQLite 数据库中，位于 `~/.quantanote/quanta_note.sqlite`。设置变更通过 Zustand store 实时同步到前端界面和 Rust 后端。

- **前端**：通过 `settingsStore` 管理所有设置状态
- **后端**：通过 `loadAllSettings` 和 `saveSettings` 命令读写设置
- **持久化**：设置以 JSON 格式存储在数据库的 `quantanote-settings` 键下

## 恢复默认设置

如果需要恢复所有设置到初始状态，可以通过以下方式：

1. 关闭 QuantaNote 应用
2. 备份数据库文件（可选）
3. 删除数据库中 `quantanote-settings` 对应的记录
4. 重新启动应用，系统将自动加载默认设置

> **提示**：日常使用中，你可以随时调整任何设置，所有更改都是即时生效且可逆的。
