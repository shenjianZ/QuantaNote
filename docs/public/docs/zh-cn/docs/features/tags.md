# 标签

标签是 QuantaNote 中组织和管理记录的核心方式。通过为记录分配彩色标签，你可以快速对记录进行分类，并通过标签过滤功能高效地找到目标内容。

与传统的文件夹分类不同，标签允许一条记录关联多个分类，提供了更灵活的组织方式。

## 创建标签

你可以随时创建新的标签来满足分类需求：

1. 打开 **标签管理器**（在设置页面或记录操作菜单中）
2. 在输入框中输入标签名称
3. 选择一个预设颜色
4. 点击创建按钮完成标签创建

创建后的标签可以在任何记录的标签选择器中使用。

标签名称建议简短明确，便于在列表中快速识别。例如：`工作`、`学习`、`灵感`、`待办` 等。

## 标签颜色

每个标签可以设置一个颜色，帮助你在视觉上快速区分不同分类。QuantaNote 提供了以下预设颜色：

| 颜色 | 色值 | 视觉效果 |
|------|------|----------|
| Cyan（青色） | `#06b6d4` | 清新的青色调 |
| Green（绿色） | `#22c55e` | 活力的绿色调 |
| Blue（蓝色） | `#3b82f6` | 经典的蓝色调 |
| Purple（紫色） | `#a855f7` | 优雅的紫色调 |
| Yellow（黄色） | `#eab308` | 温暖的黄色调 |
| Red（红色） | `#ef4444` | 醒目的红色调 |

颜色以标签徽章的形式显示在记录卡片和编辑器中，让你一眼就能识别记录的分类。

## 分配标签

为记录分配标签的操作非常简便：

1. 在记录卡片或阅读抽屉中，点击 **管理标签** 操作
2. 弹出标签选择器弹窗，显示所有可用标签列表
3. **多选操作**：勾选要分配的标签，取消勾选则移除标签
4. 确认选择后，标签立即关联到记录

每条记录可以关联任意数量的标签，实现多维度的分类管理。分配后，标签徽章会显示在记录卡片上。

## 按标签过滤

在记录库中，你可以通过标签过滤功能快速筛选记录：

- 在记录库的标签过滤区域选择一个标签
- 列表立即刷新，仅显示关联了该标签的记录
- 可以取消标签过滤以恢复显示全部记录
- 标签过滤与快捷筛选（全部/置顶/收藏）可以组合使用

标签过滤非常适合当你只需要查看某一类记录时使用，例如只看"工作"相关的记录。

## 管理标签

标签管理器提供了完整的标签维护功能：

### 重命名标签

- 在标签管理器中选择要修改的标签
- 修改标签名称后保存
- 所有关联了该标签的记录会自动更新显示

### 修改颜色

- 在标签管理器中选择标签的颜色选项
- 更换为新的预设颜色
- 标签颜色变更后，所有记录卡片上的标签徽章颜色同步更新

### 删除标签

- 在标签管理器中删除不再需要的标签
- 删除标签后，所有记录与该标签的关联自动解除
- 记录本身不会被删除，仅移除标签关联

> **注意**：删除标签操作不可撤销，请确认不再需要该标签后再执行删除。

## 标签统计

标签管理器中会显示每个标签的关联记录数量：

- 每个标签旁边显示已关联的记录总数
- 帮助你了解各分类下的记录分布情况
- 方便识别使用较少或过多的标签分类

通过标签统计，你可以更好地优化标签分类体系，保持清晰的组织结构。
