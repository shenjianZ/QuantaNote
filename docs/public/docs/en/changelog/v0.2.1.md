# v0.2.1

Dependency upgrades, input validation, error handling improvements, and accessibility fixes.

## Changed

- Upgraded rusqlite 0.31→0.35, thiserror 1→2, hashlink 0.9→0.10
- Sync state management now uses `Result` instead of `unwrap` for better error propagation
- CI concurrency groups renamed to prevent docs/site deployments from canceling each other

## Added

- Input validation for password length (≥8), tag colors, and item types
- Unit tests for sync diff module (conflict strategies, cross-table IDs, hash determinism, etc.)
- PR Check workflow (manual trigger only)

## Fixed

- TopBar compatible with non-Tauri environments (browser preview no longer errors)
- Tag loading state management — fetchTags correctly sets loading/error
- Delete account shows error toast instead of silently failing
- Editor search highlight uses DOM API instead of innerHTML replacement
- SettingsPage toggle adds `role="switch"` and `aria-checked` for accessibility
