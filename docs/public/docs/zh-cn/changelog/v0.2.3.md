# v0.2.3

新增悬浮球功能，支持桌面全局快捷操作与快速笔记。

## 新增

- 悬浮球窗口：收起时 64x64 球体，展开时 300x300 径向菜单
- 快速笔记独立窗口，支持 Markdown 编辑
- 悬浮球设置项：透明度调节、窗口置顶、开关控制
- 完整中英文国际化
- 悬浮球相关单元测试
