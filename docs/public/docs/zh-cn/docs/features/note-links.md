# 双向链接

QuantaNote 支持用 Wiki 链接把笔记连接起来。链接关系根据当前未删除笔记的正文实时解析，不需要手动维护关系数据。

## 链接语法

在 Markdown 正文中输入：

```markdown
[[目标笔记]]
[[目标笔记|自定义显示名称]]
```

第一种写法直接显示笔记标题，第二种写法使用自定义显示名称，但仍然指向“目标笔记”。代码块和行内代码中的示例不会被识别为链接。

## 阅读和导航

在记录库打开笔记后，正文中的 Wiki 链接可以直接点击：

- 目标笔记存在时，阅读抽屉会切换到目标笔记。
- 目标笔记不存在时，点击正向链接会创建同名空白笔记并打开。
- 正文下方的 **笔记链接** 面板会列出当前笔记的正向链接和反向链接。
- 点击反向链接可以回到引用当前笔记的来源笔记。

未解析的正向链接使用虚线样式和加号提示，方便区分已存在和待创建的目标。

## 关系图

点击笔记链接面板中的 **关系图**，可以查看所有未删除笔记及其已解析的连接。图中的箭头表示正文中的引用方向；未找到目标笔记的链接会显示为未解析数量提示。

关系图使用当前数据库内容生成。修改标题、正文或删除/恢复笔记后，重新打开关系图即可看到最新结果。
