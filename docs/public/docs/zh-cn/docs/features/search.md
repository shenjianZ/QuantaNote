# 全文搜索

QuantaNote 内置了强大的全文搜索功能，帮助你从大量记录中快速找到目标内容。搜索基于 SQLite 的 FTS5（Full-Text Search 5）扩展实现，采用双引擎策略，完美支持中文内容的搜索。

## 工作原理

QuantaNote 的全文搜索采用 **FTS5 unicode61 + trigram 双引擎** 架构，兼顾英文单词搜索和中文子串匹配的需求。

### 双引擎架构

| 引擎 | 分词器 | 适用场景 | 说明 |
|------|--------|----------|------|
| FTS5 主引擎 | `unicode61` | 英文单词匹配 | 按空格和标点分词，适合英文内容 |
| Trigram 引擎 | `trigram` | 中文字串匹配 | 按 3 字符滑动窗口建立索引，支持中文子串搜索 |

这种双引擎设计确保无论你的记录是英文、中文还是中英混合内容，都能获得良好的搜索体验。

### 索引机制

- 数据库中使用 `items_fts` 虚拟表存储全文搜索索引
- 通过数据库触发器在记录创建、更新、删除时自动维护索引
- 索引覆盖标题、内容和摘要三个字段
- 搜索操作直接在 SQLite 层面执行，性能优异

## 搜索方式

在记录库页面使用搜索栏进行搜索。默认是普通搜索；需要使用运算符时，在筛选面板中切换为高级搜索。

1. 点击记录库顶部的搜索输入框
2. 输入搜索关键词
3. 实时显示匹配的搜索结果

### 普通搜索

普通搜索适合日常查找。多个关键词用空格分隔时，结果需要同时包含这些关键词；中文可以直接输入连续子串。普通模式会把运算符当作普通文字处理，不会执行布尔语义。

### 高级搜索语法

高级搜索由应用解析并转换为安全查询，支持以下语法：

| 语法 | 说明 | 示例 |
|------|------|------|
| 单词搜索 | 直接输入关键词 | `笔记` |
| 多词搜索 | 空格或 `AND`，匹配所有词 | `项目 计划` |
| 短语搜索 | 双引号包裹，精确匹配词组 | `"项目计划"` |
| OR 搜索 | 匹配任一词 | `项目 OR 计划` |
| 前缀搜索 | 关键词末尾使用星号 | `项目*` |
| 排除搜索 | 使用减号或 `NOT` 排除词 | `项目 -已完成` |

高级模式下，`OR` 两侧的词组成一个可选词组，空格表示隐含 `AND`。引号未闭合或运算符缺少关键词时，查询会被拒绝并显示为空结果。

## 搜索结果

搜索结果以列表形式展示，包含以下信息：

- **匹配字段**：标记命中的标题、摘要、正文、标签、附件或版本字段
- **上下文摘要**：优先显示命中位置附近的正文或关联字段片段
- **关键词高亮**：标题和上下文中的命中词会高亮显示
- **类型图标**：显示记录的类型标识
- **标题**：记录的标题文本
- **标签**：记录关联的标签
- **时间**：记录的更新时间
- **结果总数**：显示当前条件下的完整匹配数量，并在滚动时继续加载分页结果

### 结果排序

搜索结果默认按最近更新时间排序，也可以在记录库筛选面板中切换为创建时间或标题排序。

## 索引范围

在搜索范围中勾选“正文”时，搜索覆盖记录的以下字段：

| 字段 | 说明 |
|------|------|
| 标题（title） | 记录的标题文本 |
| 内容（content） | 记录的完整 Markdown 内容 |
| 摘要（summary） | 记录的摘要文本 |

这意味着你可以通过标题中的关键词、正文中的任意内容或摘要信息来搜索记录。

### 可选搜索范围

除了正文范围外，还可以在筛选面板中选择：

| 范围 | 匹配内容 |
|------|----------|
| 标签 | 记录关联的标签名称 |
| 附件 | 附件文件名（不读取附件文件内容） |
| 版本 | 版本名称、描述、变更摘要和版本正文 |

命令面板 `Ctrl + K` 始终使用普通搜索和正文范围，适合快速导航；需要高级语法或关联数据搜索时，请使用记录库搜索栏。

## 性能说明

- FTS5 索引使搜索操作的时间复杂度远低于全表扫描
- 即使记录数量达到数千条，搜索响应时间仍在毫秒级别
- 索引的维护（创建和更新）在后台自动完成，不影响正常使用
- WAL 日志模式确保搜索和写入操作可以并发执行
