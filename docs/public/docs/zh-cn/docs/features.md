# 功能介绍

QuantaNote 是一款本地优先的桌面笔记应用，致力于提供高效、安全、流畅的信息管理体验。所有数据存储在本地 SQLite 数据库中，确保隐私和离线可用性。

以下是 QuantaNote 的核心功能模块，点击各链接了解详细用法。

## 核心模块

| 模块 | 说明 |
|------|------|
| [工作台](./workspace) | 快速捕捉灵感，输入即保存，支持 Markdown 格式化工具栏 |
| [记录库](./library) | 浏览、筛选和管理所有笔记记录，支持卡片视图和阅读抽屉 |
| [文档编辑器](./document-editor) | 全屏沉浸式编辑体验，基于 Vditor 的专业 Markdown 编辑器 |
| [Markdown 编辑器](./markdown-editor) | 即时渲染模式，完整工具栏，支持 GFM 语法和快捷键 |

## 组织与管理

| 模块 | 说明 |
|------|------|
| [标签](./tags) | 用彩色标签对记录进行分类和组织，支持按标签过滤 |
| [附件](./attachments) | 为记录关联图片、音频、视频、PDF 等文件附件 |
| [版本历史](./version-history) | 自动追踪内容变更，支持版本对比与回滚 |

## 搜索与导航

| 模块 | 说明 |
|------|------|
| [全文搜索](./search) | 基于 FTS5 的双引擎全文搜索，完美支持中文分词和子串匹配 |
| [命令面板](./command-palette) | Ctrl+K 全局快速访问，关键词搜索并直达目标记录 |

## 桌面快捷入口

| 模块 | 说明 |
|------|------|
| [悬浮球](./floating-ball) | 显示在其他窗口上方的小型快捷入口，可在当前工作流中快速捕捉笔记或打开搜索 |

## 数据安全

- **本地存储**：所有数据保存在本地 SQLite 数据库（WAL 模式），无需联网即可使用
- **数据目录**：数据文件位于 `~/.quantanote/` 目录下，可随时备份
- **自动保存**：编辑器内置防抖自动保存机制，避免数据丢失
- **版本追踪**：每次内容变更自动创建版本快照，可随时恢复

## 技术特点

- **Tauri 2.0**：Rust 后端 + React 前端，轻量高性能
- **SQLite + FTS5**：本地数据库配合全文搜索引擎
- **Vditor 编辑器**：即时渲染（IR）模式，兼顾 Markdown 纯文本与所见即所得
- **Zustand 状态管理**：响应式前端架构，流畅的用户体验
